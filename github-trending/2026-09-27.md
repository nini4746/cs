오늘 트렌딩은 에이전트 인프라 두 축이 하루 만에 다시 폭발적으로 성장한 가운데, 로컬 우선(local-first) 도구와 교육 콘텐츠가 그 옆자리를 채우는 하루입니다. 어제 상위권이었던 에이전트 조직 관리 플랫폼(paperclip)과 에이전트 기억 시스템(hindsight)이 오늘도 나란히 최상위를 지켰는데, 특히 hindsight는 어제보다 두 배 넘는 스타가 오늘 하루에만 붙었습니다. 여기에 클라우드 없이 로컬에서 돌아가는 음성 AI 스튜디오(VoiceStudio)와, 이론이 아니라 "손으로 직접 구현"하며 AI를 배우는 대형 커리큘럼(ai-engineering-from-scratch)이 함께 오르면서, 에이전트 인프라의 화려함과 별개로 "내 손으로 직접 돌리고 직접 배운다"는 흐름도 여전히 강하다는 것을 보여줍니다.

## paperclipai/paperclip

- <https://github.com/paperclipai/paperclip>
- 언어: TypeScript
- 오늘 스타: 2,527 (총 88,843)

여러 AI 에이전트를 "회사의 직원"처럼 조직도·업무·거버넌스 구조 안에서 관리하는 오픈소스 플랫폼으로, 어제에 이어 이틀 연속 트렌딩 최상위를 지켰습니다. Node.js·PostgreSQL 백엔드와 pnpm 모노레포 구성 위에 Vitest 단위 테스트와 Playwright E2E 테스트까지 갖추고 있고, 에이전트별 토큰·비용 추적과 예산 초과 시 자동 스로틀링, 승인 워크플로 같은 거버넌스 장치가 핵심입니다. 하루 만에 다시 2,500개가 넘는 스타가 붙은 것을 보면, 여러 에이전트를 동시에 굴릴 때 발생하는 "조직 운영" 문제가 실제로 많은 팀의 고민거리라는 신호로 읽힙니다.

## vectorize-io/hindsight

- <https://github.com/vectorize-io/hindsight>
- 언어: Python
- 오늘 스타: 4,463 (총 35,825)

대화 기록을 그대로 쌓는 것이 아니라 에이전트가 경험에서 배우도록 설계된 기억 시스템으로, 어제 하루 스타(2,152개)의 두 배가 넘는 4,463개가 오늘 붙으며 트렌딩 전체에서 가장 큰 폭으로 성장했습니다. 저장(retain)·검색(recall)·성찰(reflect) 세 연산으로 나뉜 구조 위에서 시맨틱·키워드·그래프·시간 기반 검색 전략을 병렬로 돌리고, PostgreSQL+pgvector 외에 오라클의 Oracle AI Database 23ai까지 엔터프라이즈 배포 옵션으로 지원합니다. LongMemEval 벤치마크에서 최고 성능을 냈다는 결과가 버지니아텍과 워싱턴포스트에 의해 독립 검증되었다는 점도 성장세를 뒷받침하는 근거로 보입니다.
