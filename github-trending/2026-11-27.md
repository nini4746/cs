## elementalsouls/Claude-BugHunter

- <https://github.com/elementalsouls/Claude-BugHunter>
- 언어: Python
- 오늘 스타: 1,615 (총 25,546)

Claude Code를 버그 바운티·외부 레드팀 어시스턴트로 바꿔주는 스킬 번들로, 사흘째 트렌딩 1위를 지키고 있습니다. Think(방법론) → Hunt webapps(취약점 클래스별 탐지 패턴) → Hit the perimeter(엔터프라이즈 공격 체인) → Ship it(검증 게이트·증거 관리)로 이어지는 4계층 구조와, 내부 AD 공격·C2·에바전은 명시적으로 범위 밖이라고 선을 긋는 README가 특징입니다. 이틀 연속 하루 1,600개 안팎의 스타가 꾸준히 붙는 걸 보면, 단발성 화제가 아니라 "에이전트에게 보안 업무를 얼마나 맡길 수 있는가"에 대한 지속적인 수요로 읽힙니다.

## jingyaogong/minimind

- <https://github.com/jingyaogong/minimind>
- 언어: Python
- 오늘 스타: 667 (총 72,093)

NVIDIA 3090 한 장으로 약 2시간, GPU 대여비 3위안 수준에 64M 파라미터급 LLM을 처음부터 훈련시키는 교육용 프로젝트입니다. 8레이어·d_model 768의 디코더 전용 트랜스포머(Pre-Norm RMSNorm, SwiGLU, RoPE+YaRN)와 4-expert top-1 MoE 변형을 PyTorch로 바닥부터 구현했고, 프리트레이닝부터 SFT, LoRA, distillation, DPO, RLAIF(PPO·GRPO·CISPO), 멀티턴 tool-use 기반 agentic RL까지 LLM 학습 파이프라인 전체를 한 레포에서 따라갈 수 있습니다. 고수준 라이브러리 뒤에 숨기지 않고 핵심 알고리즘을 직접 구현해 보여주는 구조가 꾸준한 인기의 핵심으로 보입니다.

### iximiuz/pathviz

- <https://github.com/iximiuz/pathviz> · 언어: Go · 스타: 116 · 생성일: 2026-11-23

리눅스 패킷이 어떤 Netfilter 훅을 거쳐 가는지 브라우저에서 실시간으로 보여주는 학습·데모용 시각화 도구입니다. 네트워크 디바이스(ingress/egress), 브리지(bridge 패밀리 훅), IP 레이어(PREROUTING/INPUT/FORWARD/OUTPUT/POSTROUTING, 각 raw·mangle·nat·filter 스테이지)까지 세 계층을 각각 관찰하는데, 각 네임스페이스마다 `pathviz`라는 nftables 테이블을 두고 훅 시작·끝과 각 스테이지 앞에 프로브 체인을 심어 NFLOG로 기록한 뒤, 유저스페이스에서 이를 읽어 패킷 경로를 재구성하는 구조입니다. 패킷 상태를 바꾸지 않고 관찰만 한다는 원칙, IP ID·TCP 시퀀스 번호로 NAT 전후 패킷을 추적하는 방법, NAT·필터 상호작용이나 egress 훅 커널 요구사항 같은 한계까지 README에 상세히 적어둔 점에서, 리눅스 네트워킹 내부 구조를 공부하는 데 참고하기 좋은 레포입니다.

### ArmorElectromancer62/game-server-route-racer (Detour)

- <https://github.com/ArmorElectromancer62/game-server-route-racer> · 언어: Rust · 스타: 134 · 생성일: 2026-11-16

유료 서비스(ExitLag, NoPing)의 무료 대안을 표방하는 Windows용 게임 핑 최적화 도구입니다. VPN이 아니라 게임의 UDP 트래픽만 선택적으로 릴레이 경로로 우회시키며, 5초마다 직접 경로와 릴레이 경로들의 핑·지터·손실을 경주시켜 다른 경로가 5ms 이상 3회 연속 앞설 때만 전환하고, 패킷을 두 경로로 동시에 보내 먼저 도착한 쪽만 쓰는 멀티패스 중복 전송으로 랙 스파이크를 줄이려 합니다. Wintun 어댑터로 스플릿 터널링을 구현하고, 릴레이는 등록된 게임 서버 주소로만 UDP를 전달하며 사설 IP·저번호 포트를 거부해 오픈 프록시 악용을 막는 등 구체적인 보안 설계가 돋보입니다. `detour-core`(경로 평가·중복 제거·판정 로직), `detour-relay`(릴레이), `app`(Tauri UI)으로 나눈 크레이트 분리와 Oracle Cloud 무료 티어에 릴레이를 직접 띄우는 셀프호스팅 가이드까지, 네트워크 최적화 도구를 어떻게 모듈화하고 신뢰 경계를 긋는지 보여주는 사례입니다.

### NibrasAz7/matcraft

- <https://github.com/NibrasAz7/matcraft> · 언어: Rust · 스타: 28 · 생성일: 2026-10-14

MATLAB의 M-code와 호환을 목표로 하는 순수 Rust 수치 계산 환경으로, README에서 스스로 "pre-alpha이며 Octave가 훨씬 앞서 있다"고 밝히는 솔직한 초기 프로젝트입니다. `matcore`(행렬·선형대수, 선택적 faer 백엔드), `matffi`(C FFI, 유일한 unsafe 경계), `matlang`(파서+트리워크 인터프리터와 바이트코드 실행 티어), `matplot`(wgpu 기반 2D/3D 플로팅), `engine`(모든 동작이 커맨드 ID로 노출되는 세션 레이어) 등으로 레이어를 나누고, `cargo xtask layers`로 상위 레이어(egui·wgpu·winit)에 대한 의존이 하위 레이어로 새지 않도록 강제합니다. MATLAB이나 카피레프트 코드를 참고하지 않는 클린룸 개발을 명시하고, 약 750개 M-code 파일로 구성된 공개 코퍼스를 실제 테스트 타깃으로 돌리며, `cargo xtask ci`로 포맷·clippy·테스트·레이어 검사를 묶어 게이트로 삼는 구조가 눈에 띕니다. 아직 못 한 부분(Cranelift JIT, Jupyter ZMQ 등)을 `docs/gaps.md`에 랭킹까지 매겨 공개해두는 태도도, 과장 없이 자기 위치를 측정하는 시스템 프로그래밍 프로젝트의 좋은 예로 보입니다.
