오늘 트렌딩은 "코딩 에이전트에게 무엇을 가르칠 것인가"라는 질문이 스킬(skill) 생태계 전반에서 반복해서 등장하는 하루입니다. 범용 엔지니어링 습관을 가르치는 스킬(mattpocock/skills), 출력 형식 자체를 다이어트시키는 스킬(i-have-adhd), 에디토리얼급 다이어그램을 그리게 하는 스킬(diagram-design)까지, 코드를 대신 짜주는 단계를 넘어 에이전트의 "말투"와 "취향"을 표준화하려는 흐름이 뚜렷합니다. 여기에 바이너리를 리버스 엔지니어링하는 에이전트 플랫폼(rea)과 PS5 게임을 네이티브로 변환하는 리링커(AnyPS5)가 더해지면서, 에이전트 활용이 저수준 시스템 분석과 호환성 작업까지 넓어지고 있다는 점도 눈에 띕니다.

## morluto/rea

- <https://github.com/morluto/rea>
- 언어: TypeScript
- 오늘 스타: 4,666 (총 12,586)

"Reverse Engineer Anything"이라는 이름 그대로, 바이너리와 런타임 동작을 분석해 애플리케이션이 어떻게 동작하는지 파악하도록 돕는 에이전트 기반 리버스 엔지니어링 플랫폼입니다. MCP 서버를 통해 에이전트를 Hopper·Ghidra·IDA Pro 같은 분석 백엔드와 연결하고, "디컴파일 → 이해 → 재구현"의 3단계 워크플로를 따릅니다. 모든 분석이 로컬에서 실행되고 결론에 도달한 근거(evidence trail)를 남기도록 설계했다는 점에서, 소스코드 복원을 주장하는 대신 검증 가능한 분석 과정을 쌓아가는 방식을 참고하기 좋습니다.

## mattpocock/skills

- <https://github.com/mattpocock/skills>
- 언어: Shell
- 오늘 스타: 1,406 (총 279,073)

"Skills for Real Engineers"를 내세운 AI 에이전트 스킬 모음으로, 요구사항 불일치·과도한 설명·테스트 부재·아키텍처 붕괴라는 네 가지 실패 패턴을 각각 `/grill-with-docs`, `GLOSSARY.md` 구축, `/tdd`, `/improve-codebase-architecture` 같은 스킬로 대응합니다. 사용자가 직접 호출하는 오케스트레이션 스킬과 모델이 스스로 불러오는 규율성 스킬을 구분해 둔 구조가 특징이며, `npx skills`로 설치하거나 포크해서 커스터마이징할 수 있습니다. 하루 만에 1,400개 넘는 스타가 붙은 걸 보면, "에이전트에게 엔지니어링 규율을 어떻게 주입할 것인가"라는 질문에 대한 관심이 매우 크다는 뜻으로 읽힙니다.

- 오늘 스타: 2,725 (총 8,918)

PS5 게임 실행 파일을 에뮬레이션 없이 Linux·Windows 네이티브 포맷으로 변환하는 리링커 프로젝트입니다. PS5 시스템 라이브러리를 동적 링킹용으로 재구현하고, 셰이더를 SPIR-V로 재컴파일하는 방식으로 별도 런타임 프로세스 없이 게임을 구동합니다. 상호운용성·보존·호환성 목적을 내세우며 암호화 키나 독점 소프트웨어는 배포하지 않는다고 명시하는데, 콘솔 바이너리를 PC 네이티브 코드로 옮기는 관점에서 리버스 엔지니어링과 플랫폼 호환성 작업을 공부할 때 참고할 만합니다.

## ayghri/i-have-adhd

- <https://github.com/ayghri/i-have-adhd>
- 언어: Python
- 오늘 스타: 620 (총 54,829)

코딩 에이전트의 답변이 실행 가능한 결론을 장황한 설명 속에 묻어버리는 문제를 해결하려는 출력 형식 스킬입니다. ### uccl-project/rdmatop

- <https://github.com/uccl-project/rdmatop>
- 언어: Rust · 스타 113 · 생성일 2026-03-14

RDMA(Remote Direct Memory Access) 네트워크 트래픽을 실시간으로 보여주는 `htop` 스타일 터미널 모니터입니다. Netlink의 `RDMA_NLDEV_CMD_GET`·`RDMA_NLDEV_CMD_STAT_GET`·`RDMA_NLDEV_CMD_RES_QP_GET` 명령으로 디바이스를 열거하고 하드웨어 카운터를 읽어오며, 큐 페어(QP)를 프로세스 ID와 매칭해 어떤 프로세스가 어떤 RDMA 디바이스를 쓰는지까지 보여줍니다. Cargo·PyPI·Ubuntu PPA로 배포되고 PyTorch Kineto·VizTracer·Perfetto 같은 프로파일링 도구와 연동되는 등 실무 수준의 완성도를 갖췄고, CONTRIBUTING.md에 빌드·테스트 가이드와 설계 원칙까지 문서화돼 있어 커널 netlink 인터페이스를 직접 다루는 시스템 프로그래밍 예제로 참고하기 좋습니다.

전통적인 TeX 배포판 없이도 PDF를 생성하는 Rust 기반 LaTeX 컴파일러이자 macOS 네이티브 IDE입니다. 엔진·PDF 작성기·캡처 브리지·편집 원장·프로젝트 인덱스를 각각 독립된 Rust 바이너리로 분리하고 JSON Lines 계약으로 통신시키는 프로세스 기반 아키텍처가 핵심이며, Apple M1 Max에서 pdflatex 대비 약 10배 빠른 47.4ms 렌더링을 측정해 공개하는 등 구체적인 성능 데이터를 문서화했습니다. 지원하지 않는 LaTeX 구문은 조용히 무시하지 않고 진단으로 알려주며 `flashtex supported`로 정확한 커버리지를 보여주는 점, 매 푸시마다 모든 크레이트와 Mac·iOS 앱을 빌드·테스트하는 CI까지 갖춘 점에서 완성도가 높습니다.

### NeverSight/NeverD

- <https://github.com/NeverSight/NeverD>
- 언어: C++ · 스타 79 · 생성일 2026-05-20 (WIP)

PE·ELF·Mach-O 네이티브 바이너리와 EVM·Solana SBF 스마트 컨트랙트 바이트코드를 분석해 LLVM IR이나 C/Rust/Solidity 소스로 복원하는 바이너리 분석·디컴파일 엔진입니다. "Binary → Loader+DebugInfo → Capstone decode → LowIR → MedIR → [lift/decompile/patch]"라는 다단계 IR 파이프라인을 두고, 리프터가 없는 명령어는 추측하거나 조용히 NOP으로 넘기지 않고 반드시 `UnliftedInstruction` 예외를 던지는 "엄격한 기본 동작" 원칙을 지킵니다. Unicorn 에뮬레이션을 이용한 시맨틱 라운드트립 검증, CTest 레이블, SHA-256으로 검증하는 LLVM 아티팩트 캐싱 등 테스트·빌드 체계가 꼼꼼해, 디컴파일러의 IR 설계와 신뢰성 확보 방법을 공부하기 좋은 프로젝트입니다.
