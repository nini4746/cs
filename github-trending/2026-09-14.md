## JustVugg/colibri

- <https://github.com/JustVugg/colibri>
- 언어: C
- 오늘 스타: 2,233 (총 31,400)

7B부터 2.8T 파라미터급까지 9개 모델 계열(GLM-5.2/5.3, DeepSeek V4 계열, Qwen, Kimi K3 등)을 소비자 하드웨어에서 돌리기 위한 추론 엔진입니다. 핵심은 VRAM·RAM·NVMe를 하나의 메모리 계층으로 다루는 "weight JIT" 전략으로, 어텐션·임베딩 같은 dense 레이어는 int4로 양자화해 RAM에 상주시키고(약 9.9GB), 19,456개에 달하는 routed expert는 디스크에 두었다가 필요할 때 스트리밍합니다. 레이어별 LRU 캐시가 사용 패턴을 학습해 자주 쓰는 expert를 미리 고정하고, 라우터가 다음 레이어에서 필요한 expert를 71.6% 정확도로 미리 예측해 prefetch하는 부분이 특히 흥미롭습니다. Python 런타임 없이 모델 계열마다 C 파일 하나로 구현된 순수 C 코드베이스라는 점도, 추론 엔진을 밑바닥부터 설계할 때 참고할 만한 지점입니다.
