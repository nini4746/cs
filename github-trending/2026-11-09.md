## anthropics/skills

- <https://github.com/anthropics/skills>
- 언어: Markdown
- 오늘 스타: 1,052 (총 190,383)

Claude가 특정 작업을 더 안정적으로 반복 수행하도록 동적으로 불러오는 "에이전트 스킬"의 공식 예제 저장소로, Agent Skills 표준(agentskills.io)의 레퍼런스 구현 역할도 합니다. 각 스킬은 `name`과 `description`만 필수인 YAML 프런트매터를 가진 `SKILL.md` 파일 하나로 정의되고, 문서 작업에 쓰이는 `docx`·`pdf`·`pptx`·`xlsx` 스킬은 실제 Claude의 문서 기능을 구동하는 프로덕션 코드가 그대로 공개돼 있습니다. "절차적 지식"을 코드가 아니라 마크다운 지침과 리소스 폴더로 패키징해 모델에 주입한다는 아이디어 자체가, 에이전트에게 새 능력을 가르치는 최소 단위를 어떻게 설계할지 보여주는 참고 자료입니다.
