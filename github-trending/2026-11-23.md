### mindspore-ai/dvm

- <https://github.com/mindspore-ai/dvm>
- 언어: C++
- 생성일: 2026-09-18 (스타 111)

Huawei MindSpore 조직이 만든 "Device Virtual Machine"으로, 딥러닝 연산자들을 실행 시점의 실제 텐서 shape에 맞춰 즉석에서 컴파일하고 융합(fusion)해 실행하는 런타임입니다. 호스트 컴파일러가 연산자 그래프를 "타일 레벨 바이트코드"로 번역하고, 디바이스 가상머신이 이를 해석해 실제 연산을 수행하는 구조로, 동적 shape와 동적 그래프는 물론 정적 그래프 융합과 사용자 정의 커널까지 지원합니다. MindSpore와 TorchNPU가 실제로 이 프로젝트를 연산자 자동 융합 엔진으로 사용하고 있고, Huawei Ascend NPU와 NVIDIA GPU를 모두 대상으로 한다는 점에서, 실무에서 쓰이는 "컴파일러+가상머신" 조합이 딥러닝 추론 최적화에 어떻게 쓰이는지 엿볼 수 있는 프로젝트입니다.

### baseguard/hangar

- <https://github.com/baseguard/hangar>
- 언어: Swift
- 생성일: 2026-11-06 (스타 102)

Claude Code나 Codex 같은 AI 코딩 에이전트를 Apple Silicon Mac 위의 격리된 가상머신 안에서 돌리기 위한 macOS 앱 겸 CLI 도구입니다. VM은 명시적으로 공유한 폴더 외에는 호스트 파일 시스템을 볼 수 없고, 허용 목록으로 접근 가능한 사이트를 제한하거나 네트워크를 완전히 차단할 수 있으며, 모든 DNS 조회와 연결을 VM 바깥(호스트 쪽)에서 기록합니다. API 키는 macOS Keychain에 보관하고 VM에는 더미 값만 주입한 뒤 허용된 호스트로 가는 요청에만 실제 키를 바꿔 끼워 넣는 방식으로, 디스크 스냅샷과 클로닝을 지원해 여러 에이전트를 병렬로 격리 실행할 수 있게 해줍니다. 에이전트에게 승인 없이 셸 권한을 주면서도 호스트를 안전하게 지키려는 설계를 가상화 기술로 구체적으로 풀어낸 사례입니다.
