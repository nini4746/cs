오늘 GitHub 트렌딩은 지난 며칠째 상위권을 지키던 에이전트 스킬·테스트 도구들이 오늘도 그대로 자리를 지키면서, 그 사이에 전혀 다른 성격의 프로젝트 하나가 끼어든 하루입니다. 자연어로 쓴 테스트를 에이전트가 직접 수행하는 tester-army/e2e, 엔지니어링 습관을 스킬로 묶은 mattpocock/skills, CAD·로보틱스까지 다루는 earthtojake/text-to-cad, "AI 티"를 지우는 디자인 스킬 pbakaus/impeccable이 나란히 또 트렌딩에 올라 "에이전트에게 전문 영역의 암묵지를 넘기는" 흐름이 하루 이틀의 유행이 아니라 꾸준한 추세임을 보여줍니다. 그 옆에 PS5 실행 파일을 에뮬레이션 없이 Linux·Windows 네이티브 바이너리로 바꿔주는 리버스 엔지니어링 프로젝트 boykopovar/AnyPS5가 깜짝 등장한 것은, 에이전트 열풍과 무관하게 콘솔 바이너리 호환 레이어 같은 전통적인 시스템 프로그래밍 영역도 여전히 큰 주목을 받는다는 신호로 읽힙니다.

## tester-army/e2e

- <https://github.com/tester-army/e2e>
- 언어: TypeScript
- 오늘 스타: 1,720 (총 5,785)

자연어로 "무엇을 테스트할지" 적으면 에이전트가 웹(Playwright)·모바일을 직접 조작해 검증하고, 한 번 검증된 스텝은 이후 LLM 추론 없이 그대로 리플레이하는 e2e 테스트 프레임워크입니다. 이틀 전 트렌딩에 올랐을 때 2,601개였던 총 스타가 오늘 하루 만에 1,720개가 더 붙어 5,785개로 뛴 것을 보면, "자연어 테스트 작성"과 "CI에서의 결정론적 재현성"을 동시에 만족시키려는 수요가 매우 빠르게 확산되고 있다는 뜻으로 보입니다. 테스트를 코드가 아니라 자연어로 먼저 적고, 검증된 동작을 캐싱해 비용과 신뢰성을 동시에 잡는 설계를 참고할 만합니다.

## mattpocock/skills

- <https://github.com/mattpocock/skills>
- 언어: Shell
- 오늘 스타: 1,028 (총 277,690)

한 개발자(Matt Pocock)가 실전에서 직접 쓰는 엔지니어링 습관과 절차를 Claude Code 등 에이전트용 스킬 파일로 정리해둔 모음입니다. 이번 달 들어 벌써 여러 차례 트렌딩 상위권에 다시 오를 만큼 꾸준히 스타가 붙고 있는데, 총 스타가 20만 대 후반까지 쌓인 것을 보면 "개인의 암묵지를 스킬 파일로 명문화해 공개한다"는 포맷 자체가 매우 넓은 공감을 얻고 있다는 신호입니다. 마케팅(marketingskills)·디자인(impeccable, hallmark) 등 다른 전문 영역의 스킬 라이브러리와 나란히 놓고 보면, "전문가의 습관을 어떻게 스킬 단위로 쪼개 문서화하는가"라는 패턴을 비교해보기 좋습니다.

## earthtojake/text-to-cad

- <https://github.com/earthtojake/text-to-cad>
- 언어: Python
- 오늘 스타: 620 (총 17,773)

자연어나 이미지로부터 CAD 모델·치수 도면·로봇 기술기술서(URDF/SRDF)·가공용 G-code까지 만들어주는 에이전트 스킬 모음으로, 이틀 전에도 트렌딩에 올랐던 프로젝트입니다. Open CASCADE 커널을 감싼 `build123d` 위에 CAD·도면·로보틱스 시뮬레이션·제조 검증까지 12개 이상의 전문 스킬을 쌓아올린 구조가 그대로 이어지는데, 짧은 기간 안에 다시 620개의 스타가 붙은 것을 보면 소프트웨어 바깥의 물리적 제조 파이프라인까지 에이전트가 다루게 만드는 시도에 대한 관심이 일회성이 아니라는 점을 보여줍니다.

## boykopovar/AnyPS5

- <https://github.com/boykopovar/AnyPS5>
- 언어: C++
- 오늘 스타: 943 (총 5,605)

PS5용 실행 파일을 에뮬레이션이나 별도 런타임 없이 Linux·Windows의 네이티브 포맷으로 직접 변환해 실행하는 "relinker" 프로젝트입니다. PS5 시스템 라이브러리(PRX)를 동적 링킹용으로 재구현하고, SPIR-V를 생성하는 자체 셰이더 리컴파일러까지 갖추고 있는데, README에 따르면 2D 플랫포머 게임 "Dreaming Sarah"가 GTX 1050 Ti·i5-7500급의 평범한 하드웨어에서 60fps로 안정적으로 돌아간다고 밝히고 있습니다. 바이너리 변환과 셰이더 재컴파일이라는, 흔히 에뮬레이터가 다루는 문제를 "에뮬레이션이 아니라 재링킹"이라는 다른 접근으로 풀어내는 방식이 눈에 띄는 프로젝트입니다.

## pbakaus/impeccable

- <https://github.com/pbakaus/impeccable>

- 오늘 스타: 947 (총 77,456)

Inter 폰트, 보라-파랑 그라데이션처럼 AI가 만든 디자인에서 반복적으로 나타나는 "티"를 없애기 위해, 61개의 결정론적 감지 규칙과 LLM 기반 비평 체크를 결합한 디자인 스킬입니다.
