## NVIDIA/OpenShell

- <https://github.com/NVIDIA/OpenShell>
- 언어: Rust
- 오늘 스타: 1,280 (총 11,675)

자율 AI 에이전트가 파일·API·자격증명에 무제한 접근 없이 안전하게 닿을 수 있게 만든 런타임/샌드박스입니다. 커널 수준 격리로 에이전트별 파일 접근과 시스템 콜을 제한하고, 정책 변경은 형식 검증을 거쳐 위험한 권한 부여를 사전에 잡아내며, 에이전트는 실제 자격증명을 절대 보지 못하고 승인된 요청에만 주입되는 구조가 핵심입니다. Rust로 작성한 커널 로직 위에 Python/TypeScript SDK를 올리고 게이트웨이-슈퍼바이저-샌드박스 아키텍처, Kubernetes/Docker 배포까지 갖췄습니다. 어제보다 스타 증가폭이 더 커졌는데, "에이전트 함대"를 실제 운영 환경에 풀 때 정책 기반 격리를 어떻게 설계하는지 참고하기 좋습니다.

## debpalash/VoiceStudio

- <https://github.com/debpalash/VoiceStudio>
- 언어: Python
- 오늘 스타: 3,481 (총 49,914)

로컬에서 완전히 동작하는 오픈소스 음성 AI 데스크톱 앱으로, ElevenLabs의 로컬 대안을 표방합니다. voice cloning, 텍스트 설명만으로 목소리를 만드는 voice design, 영상 더빙, 받아쓰기·전사, 646개 언어의 오디오북 생성까지 한 앱에서 처리합니다. Electron 데스크톱 UI, Python FastAPI 백엔드, TypeScript/Node 프런트엔드로 이루어진 폴리글랏 구조이고 기본 음성 합성 엔진으로 k2-fsa/OmniVoice를 쓰되 다른 TTS/STT 백엔드로도 교체할 수 있게 설계했습니다. 이틀째 하루 수천 스타씩 붙고 있는데, 여러 음성 모델을 플러그형으로 갈아끼울 수 있게 로컬 우선 아키텍처를 짜는 법을 참고할 만합니다.

## mvschwarz/openrig

- <https://github.com/mvschwarz/openrig>
- 언어: TypeScript
- 오늘 스타: 622 (총 2,777)

Claude Code와 Codex 같은 여러 코딩 에이전트를 하나의 팀처럼 조율하는 오케스트레이션 시스템입니다. Node.js 데몬(Hono HTTP)과 SQLite, tmux 세션 관리를 뼈대로 CLI·TUI·MCP 서버·웹 UI 인터페이스를 두고, YAML로 에이전트 토폴로지를 선언(RigSpec)한 뒤 `rig up` 한 번으로 팀을 띄우는 구조입니다. `rig send`/`rig broadcast`/`rig chatroom` 같은 통신 도구와 토폴로지 스냅샷/복원까지 갖춰, 터미널이 에이전트 세션으로 뒤엉키는 문제를 CLI/데몬/런타임 어댑터 계층으로 어떻게 정리하는지 참고할 만합니다.
