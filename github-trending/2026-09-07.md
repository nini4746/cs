## heygen-com/hyperframes

- <https://github.com/heygen-com/hyperframes>
- 언어: TypeScript
- 오늘 스타: 734 (총 45,078)

HTML·CSS·미디어·애니메이션을 결정론적인 MP4 영상으로 렌더링하는 오픈소스 프레임워크입니다. React 컴포넌트를 요구하는 Remotion과 달리 순수 HTML에 타이밍·트랙 정보를 담은 data attribute만 붙이면 되고, 헤드리스 Chrome으로 프레임을 캡처한 뒤 FFmpeg로 인코딩해 "같은 입력이면 같은 프레임, 같은 출력"을 보장하는 것이 핵심입니다. CI 파이프라인에서 재현 가능한 영상 렌더링이 왜 어려운지, 그리고 그 문제를 브라우저 렌더링 엔진과 인코더 조합으로 어떻게 결정론적으로 풀어내는지 살펴보기 좋은 프로젝트입니다.

## microsoft/markitdown

- <https://github.com/microsoft/markitdown>
- 언어: Python
- 오늘 스타: 771 (총 179,584)

PDF, Word, Excel, PPT, 이미지, 오디오, HTML, ZIP, 유튜브 URL 등 다양한 포맷을 Markdown으로 변환하는 마이크로소프트의 Python 유틸리티입니다. "GPT-4o 같은 주류 LLM은 Markdown을 네이티브로 이해한다"는 전제 아래, 문서의 제목·목록·표·링크 구조를 최대한 보존하면서도 토큰 효율이 높은 형태로 바꾸는 것을 목표로 합니다. 포맷별 선택적 의존성과 플러그인 아키텍처로 핵심 코드를 건드리지 않고도 확장할 수 있게 설계되어 있어, LLM 파이프라인 앞단의 "문서 전처리기"를 어떻게 모듈화하는지 참고할 만합니다.

봇 탐지를 우회하는 Firefox 포크 Camoufox를 감싸는 REST API 서버로, AI 에이전트가 원본 HTML 대신 안정적인 엘리먼트 식별자와 접근성 스냅샷(원본 대비 약 90% 작은 크기)으로 웹을 탐색하게 해줍니다. `navigator.hardwareConcurrency`, WebGL 렌더러, AudioContext, 화면 정보 같은 핑거프린팅 신호를 JavaScript가 관측하기 전에 C++ 레벨에서 스푸핑한다는 점이 특징이며, 유휴 상태에서 약 40MB만 사용하도록 지연 실행·자동 종료를 구현해 Raspberry Pi 같은 저사양 환경에서도 돌아가게 만들었습니다. 브라우저 자동화 스택에서 "탐지 신호가 어느 계층에서 새는지"와 "그 신호를 어느 계층에서 막아야 하는지"를 함께 보여주는 사례로 공부할 가치가 있습니다.
