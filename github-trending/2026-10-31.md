## mattpocock/skills

AI 코딩 에이전트(Claude Code, Codex, Copilot, Gemini CLI)를 위한 마크다운 스킬 모음으로, "개발 과정의 주도권을 프레임워크가 아니라 엔지니어가 쥐고 있어야 한다"는 문제의식을 내세웁니다. 스킬을 사용자가 직접 호출하는 것과 에이전트가 자율적으로 호출하는 것으로 나누고, 사용자 호출 스킬이 모델 호출 스킬을 부르는 건 가능하지만 다른 사용자 호출 스킬을 부르지는 못하게 구조를 제한해, 작업 흐름의 통제권이 한쪽으로 쏠리지 않도록 설계한 점이 특징입니다. 작업 전 요구사항을 꼬치꼬치 묻는 "그릴링" 세션, 공유 용어집(GLOSSARY.md)으로 장황한 설명을 줄이는 장치, red-green-refactor TDD와 구조화된 디버깅 피드백 루프까지, 코드 품질보다 "에이전트와 함께 일하는 과정" 자체를 설계 대상으로 삼은 접근이어서, 최근 며칠 트렌딩에 오른 UI 디자인 중심 스킬들과는 결이 다른 각도의 시도입니다.

단일 `.ddb` 파일과 `.wal` 사이드카 로그로 동작하는 임베디드 관계형 데이터베이스 엔진으로, B+Tree 테이블과 보조 인덱스, LRU 캐시와 프리리스트를 갖춘 페이저, 장애 주입이 가능한 VFS 레이어로 구성돼 있습니다. 한 명의 쓰기자와 다수의 동시 읽기자를 스냅샷 격리로 지원하고, 여러 OS 프로세스가 바이트 레인지 락과 재구성 가능한 `.coord` 사이드카로 서로 조율하도록 설계했으며, PostgreSQL과 비슷한 SQL로 재귀 CTE·윈도 함수·트리거·세이브포인트와 트라이그램·BM25 전문검색·공간 인덱스까지 지원한다고 밝히고 있습니다. 단위 테스트·속성 테스트·크래시 주입·차분 테스트에 더해 벤치마크 결과의 신뢰 범위(단일 프로세스 결과가 다중 프로세스 동작을 보장하지 않는다는 점)까지 README에서 솔직히 구분해 설명하는 점에서, 스타 수는 적지만 엔진 설계와 검증 방법론 모두 공부할 가치가 있는 프로젝트로 판단했습니다.

### desertwitch/par2cron

ZFS 같은 파일시스템 전체를 쓰지 않고도, 거의 변경되지 않는 미디어·백업 디렉터리에만 선택적으로 비트로트 방어를 걸어주는 Go CLI입니다. 디렉터리에 빈 `_par2cron` 마커 파일을 두면 `par2cmdline`을 감싸 PAR2 패리티 세트를 만들고, 중앙 데이터베이스 없이 파일 옆의 JSON 매니페스트와 락 파일로 상태를 관리해 디렉터리를 다른 호스트로 옮겨도 그대로 동작하게 합니다. `create`·`verify`·`repair` 세 개의 크론 작업으로 나눠 돌리면서 검증 우선순위 큐(매니페스트 없는 세트 → 검증 안 된 세트 → 복구 플래그 세트 → 오래된 순)를 시간 예산에 맞춰 잘라내는 스케줄링 로직과, lint·테스트·퍼징·커버리지 CI 배지, 그리고 "수정된 파일을 손상으로 오인할 수 있다"는 한계를 숨기지 않고 적어둔 섹션까지 갖추고 있어, 실무형 시스템 도구를 어떻게 문서화하고 안전장치를 두는지 참고하기 좋습니다.
