## huggingface/speech-to-speech

- <https://github.com/huggingface/speech-to-speech>
- 언어: Python
- 오늘 스타: 627 (총 8,351)

VAD → STT → LLM → TTS 네 단계를 독립된 스레드로 연결하고 OpenAI Realtime API 호환 WebSocket으로 노출하는 로컬 음성 에이전트 파이프라인입니다. 각 단계 백엔드를 자유롭게 교체할 수 있게 설계했고(STT는 Parakeet TDT 기본, TTS는 Qwen3-TTS 기본), MLX·GGML 등 하드웨어별 최적화 경로까지 지원하며 실제로 Reachy Mini 로봇 수천 대에 프로덕션으로 올라가 있습니다. 어제에 이어 오늘도 스타가 크게 늘고 있는 것을 보면, 완전 로컬 배포가 가능한 저지연 음성 대화 시스템에 대한 관심이 계속되고 있다는 신호로 읽힙니다.

## different-ai/openwork

- <https://github.com/different-ai/openwork>
- 언어: TypeScript
- 오늘 스타: 916 (총 18,446)

Claude Code, Cursor, Codex, ChatGPT 등 여러 AI 도구에서 같은 스킬·MCP·연결된 서비스를 공유해 쓸 수 있게 만든 오픈소스 데스크톱 앱으로, Claude Cowork의 대안을 표방합니다. Electron과 Vite 기반 프런트엔드에 Node.js 원격 MCP 서버를 붙인 구조이며, `search_capabilities`·`execute_capability` 같은 MCP 도구로 여러 에이전트 하네스와 호환되게 만들고, 팀 단위 접근 제어·스킬 배포를 위한 엔터프라이즈 제어판(OpenWork Den)까지 포함하고 있습니다. 개별 도구마다 따로 설정하던 스킬과 연결을 하나의 계층으로 추상화하려는 시도라는 점에서, 에이전트 하네스 표준화 흐름(어제의 ECC)이 데스크톱 앱 형태로도 이어지고 있다는 것을 보여줍니다.

- 오늘 스타: 12 (총 10,362)
