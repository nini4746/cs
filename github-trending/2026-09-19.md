오늘 트렌딩은 "에이전트를 어디에 풀어놓을 것인가"라는 질문이 스킬, 개발 환경, 컴퓨터 사용까지 여러 층위에서 겹치는 하루입니다. Cloudflare의 보안 감사 스킬이 이틀 연속 1위 근처를 지키며 15,000스타를 넘겼고, 그 옆에서 Addy Osmani가 내놓은 스킬 모음은 스펙-계획-구현-검증-리뷰-배포로 이어지는 개발 생애주기 전체를 슬래시 커맨드로 패키징합니다. Coder는 에이전트를 실행할 클라우드 개발 환경 자체를 자체 호스팅으로 제공하고, Cua는 에이전트가 macOS·클라우드 데스크톱을 직접 조작하게 하는 컴퓨터 사용 인프라를 내세우면서, "에이전트에게 무엇을 시킬지"를 넘어 "에이전트를 어떤 환경에 배치할지"가 오늘 트렌딩의 공통 주제로 보입니다.
