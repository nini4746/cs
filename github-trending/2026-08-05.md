## firecrawl/pdf-inspector

- <https://github.com/firecrawl/pdf-inspector>
- 언어: Rust
- 오늘 스타: 1,583 (총 11,029)

PDF가 텍스트 기반인지 스캔본인지 OCR 없이 판별하고, 위치 정보를 보존한 채 텍스트를 뽑아 마크다운으로 바꿔주는 순수 Rust 라이브러리입니다. `lopdf` 하나에만 의존해 PDF를 한 번 파싱한 뒤 그 결과를 판별 단계와 추출 단계에서 재사용하는 구조로, 판별에는 10~50ms, 추출에는 약 150ms가 걸린다고 밝히고 있고, PDF 그리기 연산 기반의 사각형 탐지와 정렬 휴리스틱을 함께 써서 표를 이중으로 검출하는 점도 눈에 띕니다. Python·Node.js·브라우저 WASM·Rust CLI까지 바인딩을 제공해 페이지 단위로 OCR 여부를 선택할 수 있게 하는 설계는, 문서 처리 파이프라인에서 비용이 큰 ML 기반 OCR을 언제 걸러낼지 고민할 때 참고할 만합니다.
