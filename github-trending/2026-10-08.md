## thedotmack/claude-mem

- <https://github.com/thedotmack/claude-mem>
- 언어: TypeScript
- 오늘 스타: 662 (총 98,173)

Claude Code 세션 간 맥락을 유지시키는 영속 메모리 시스템으로, 도구 사용 기록(tool usage observations)을 자동으로 캡처해 요약한 뒤 다음 세션에서 꺼내 쓸 수 있게 해줍니다. SessionStart·UserPromptSubmit·PostToolUse·Stop·SessionEnd 다섯 가지 lifecycle hook과 Bun으로 띄우는 로컬 HTTP 워커, SQLite+FTS5 저장소, Chroma 벡터 DB를 결합한 하이브리드 검색 구조가 특징입니다. 검색 인덱스 조회(search) → 시간순 맥락(timeline) → 전체 세부 정보(get_observations)로 이어지는 3단계 조회 방식으로 토큰 사용량을 약 10배 줄였다고 밝히는데, 에이전트의 "기억"을 스킬이 아니라 별도 저장·검색 계층으로 다루는 접근이라는 점에서 오늘 트렌딩의 다른 스킬 생태계 레포들과 결이 다릅니다.

### wkoszek/emuko

- <https://github.com/wkoszek/emuko>

Rust로 작성된 RISC-V 에뮬레이터로, RV64IMAFDC 명령어 집합과 M/S/U 권한 레벨, Sv39 가상 메모리를 구현해 실제로 Linux를 부팅시킵니다.
