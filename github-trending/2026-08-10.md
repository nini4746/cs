## semantica-agi/semantica

- <https://github.com/semantica-agi/semantica>
- 언어: Python
- 오늘 스타: 967 (총 3,831)

LLM과 에이전트 프레임워크 아래에 놓이는 "그래프 네이티브" 컨텍스트 관리 인프라로, 임베딩 유사도 대신 지식 그래프에 의미와 근거를 저장하는 것을 목표로 합니다. Ingest→Parse→Normalize→Split→Extract→Conflict Detection→Dedup→Knowledge Graph로 이어지는 파이프라인 위에서 RDF(Oxigraph, Blazegraph)와 LPG(Neo4j)를 함께 쓰는 폴리글랏 저장소, Rete·Datalog·SPARQL 추론 엔진을 제공합니다. 가장 특징적인 부분은 `record_decision()`과 `trace_decision_chain()`으로 모든 AI의 판단을 영구적인 그래프 노드로 남기는 "결정 지능"과 W3C PROV-O 기반 계보 추적으로, 금융·의료·정부처럼 규제가 강한 도메인에서 설명 가능한 AI 인프라를 자체 호스팅으로 구축하려는 시도입니다. 임베딩 기반 RAG가 "왜 그렇게 답했는지" 설명하기 어렵다는 한계를, 그래프 구조로 어떻게 보완하는지 살펴보기 좋은 프로젝트입니다.
