## vllm-project/vllm

- <https://github.com/vllm-project/vllm>
- 언어: Python
- 오늘 스타: 439 (총 94,731)

UC 버클리 Sky Computing Lab에서 시작된 LLM 추론·서빙 엔진으로, 어텐션 키·값 메모리를 관리하는 PagedAttention, 연속 배칭(continuous batching)과 chunked prefill·프리픽스 캐싱 같은 스케줄링 기법, FlashAttention·CUTLASS 등 다양한 커널과 FP8/INT4 양자화, 투기적 디코딩(speculative decoding)까지 LLM 서빙에 필요한 거의 모든 최적화 기법을 한 프로젝트 안에 담고 있습니다. OpenAI 호환 API뿐 아니라 Anthropic Messages API까지 서빙 인터페이스로 지원하고, NVIDIA·AMD GPU는 물론 TPU와 CPU까지 폭넓은 하드웨어를 지원한다는 점에서, "모델을 어떻게 빠르고 싸게 서빙할 것인가"라는 질문에 대한 업계 표준 답안에 가까운 프로젝트입니다. 9만 개가 넘는 스타와 2천 명이 넘는 기여자 수는 이 프로젝트가 단일 연구실 도구를 넘어 LLM 인프라의 공통 기반이 되었음을 보여줍니다.

- 언어: TypeScript
- 오늘 스타: 1,543 (총 100,729)

Claude Code, Codex, OpenCode 등 25개 이상의 CLI 에이전트를 각각 독립된 git worktree에서 동시에 돌리고 결과를 비교·병합하는 데스크톱 오케스트레이터입니다. 같은 프롬프트를 여러 에이전트에 동시에 보내 결과를 나란히 비교하는 병렬 worktree 구조와, AI가 만든 diff에 줄 단위로 코멘트를 남기는 리뷰 도구가 특징인데, 어제 하루 동안 총 스타가 99.3k에서 100.7k로 늘며 누적 10만 스타를 넘겼습니다. "에이전트 한 대"가 아니라 "에이전트 함대"를 다루는 작업 단위가 꾸준히 지지를 얻고 있다는 뜻으로 보입니다.

## headroomlabs-ai/headroom

- <https://github.com/headroomlabs-ai/headroom>
- 언어: Python
- 오늘 스타: 477 (총 77,062)

에이전트에게 전달되기 전에 도구 출력, 로그, 파일, RAG 청크를 압축하는 컨텍스트 압축 레이어입니다. 콘텐츠 종류별로 압축기를 고르는 ContentRouter가 핵심 아키텍처로, JSON은 SmartCrusher, 소스 코드는 AST를 인식하는 CodeCompressor, 일반 텍스트는 자체 Hugging Face 모델(Kompress-v2-base)로 처리하고, 프롬프트를 고치는 대신 캐시를 깨뜨릴 변동 요소만 표시하는 CacheAligner로 프로바이더의 KV 캐시 프리픽스를 보존합니다. 압축된 원본은 로컬에 캐시되어 필요하면 그대로 복원할 수 있고, Claude Code·Codex·Cursor·Aider 등 여러 에이전트에 코드 수정 없이 씌울 수 있는 프록시·래퍼 방식을 제공한다는 점에서, "에이전트의 토큰 비용을 어떻게 줄일 것인가"라는 실용적인 문제를 정면으로 다루는 프로젝트입니다. 다만 21~57% 토큰 절감과 정확도 유지라는 수치는 자체 벤치마크 결과라는 점은 참고할 필요가 있습니다.

remark와 동일한 mdast 트리를 만들어내는 것을 목표로 하는 Markdown·MDX 파서·직렬화기입니다. 스캐너 → 블록 파싱 → 지연된 인라인 파싱 → 오토링크 처리 → 트리 구성으로 이어지는 파이프라인을 재사용 가능한 타입 배열 위에서 돌리고, 문자 단위 검사 대신 네이티브 문자열 탐색으로 구문 후보를 찾는 등 성능을 의식한 구현이 특징입니다. 가장 눈에 띄는 점은 테스트 방법론인데, 실제 remark 스택을 오라클로 고정해두고 CommonMark·GFM·micromark 등 여러 소스에서 모은 9,854개의 적합성 픽스처 전체가 remark와 정확히 같은 트리(위치 정보, estree 데이터, 에러까지)를 만들어내는지 비교하는 차등 테스트(differential testing)를 쓰고 있습니다. "똑같은 동작을 내는 더 빠른 구현"을 만들 때 그 동등성을 어떻게 검증하는지 보여주는 좋은 예시입니다.
