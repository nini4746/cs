## vercel-labs/agent-desktop

- 언어: Rust
- 오늘 스타: 3,792 (총 11,864)

## JustVugg/colibri

- <https://github.com/JustVugg/colibri>
- 언어: C
- 오늘 스타: 803 (총 47,014)

"작은 엔진, 거대한 모델"을 표방하며 수백억 파라미터의 MoE 언어모델을 GPU 없이도 돌리려는 C 기반 추론 엔진입니다. 토큰마다 활성화되는 전문가(expert)가 일부뿐이라는 점을 이용해, 자주 쓰는 전문가는 GPU에, 중간 빈도는 RAM에, 드물게 쓰는 전문가는 NVMe 디스크에 두고 라우터 요청 시점에 읽어오는 계층형 배치를 씁니다. 모델별로 하나의 C 소스 파일만 쓰고 BLAS 의존성도 없는 구조라서, 디스크·RAM·GPU를 "티어"로 다루며 추론 비용을 낮추는 엔지니어링을 뜯어보기 좋습니다. 다만 디스크 스트리밍 경로의 속도는 공식 수치로도 초당 0.05~0.1 토큰 수준으로 느려서, 속도와 접근성을 맞바꾸는 트레이드오프라는 점은 감안해야 합니다.

## p-e-w/heretic

- <https://github.com/p-e-w/heretic>
- 언어: Python
- 오늘 스타: 699 (총 38,541)

추가 학습 없이 기존 언어모델의 거부(refusal) 응답을 줄이는 도구로, 대조되는 예시 프롬프트와 점수 함수로 모델을 조작하는 ablation 계열 기법(기본값은 자체 개발한 ARA, 방향성 ablation도 선택 가능)을 씁니다. Optuna의 TPE 최적화기가 거부율과 KL 발산 같은 점수를 기준으로 수정 파라미터를 탐색하고, 결과를 reproduce.json으로 내보내면 다른 사람도 같은 수정을 재현할 수 있게 한 점이 특징입니다. RTX 3090 한 장으로 30~40분이면 처리된다는 점에서 모델 수정을 소비자급 하드웨어로 끌어내렸다는 평가를 받고 있는데, 안전장치를 제거하는 용도로 쓰일 수 있다는 점도 함께 알아둘 필요가 있습니다.
