## elementalsouls/Claude-BugHunter

- <https://github.com/elementalsouls/Claude-BugHunter>
- 언어: Python
- 오늘 스타: 1,600 (총 24,009)

Claude Code를 버그 바운티·외부 레드팀 어시스턴트로 바꿔주는 스킬 번들로, 이틀 연속 트렌딩 1위를 지키고 있습니다. Think(방법론) → Hunt webapps(취약점 클래스별 탐지 패턴·체인 템플릿) → Hit the perimeter(M365/Entra, Okta, VPN 어플라이언스 같은 엔터프라이즈 공격 체인) → Ship it(검증 게이트·심각도 매핑·증거 관리)로 이어지는 4계층 구조를 갖추고, 주제에 따라 스킬이 자동으로 로드되는 방식입니다. README가 내부 AD 공격·C2·포스트 익스플로잇·에바전은 명시적으로 범위 밖이라고 밝히고 있어, 스킬 설계를 "어디까지 허용하고 어디서 선을 긋는가"의 관점에서 참고하기 좋습니다.

## obra/superpowers

- 언어: Shell
- 오늘 스타: 853 (총 327,163)

코딩 에이전트에게 "완전한 소프트웨어 개발 방법론"을 입히는 조합형 스킬 프레임워크입니다. 사용자 의도를 먼저 브레인스토밍으로 끌어내고, 초보 엔지니어도 따라갈 수 있는 수준의 상세 계획을 세운 뒤, 승인을 받고서야 작업을 실행하는 순서를 강제합니다. 테스트 주도 개발(red-green-refactor), 작업 사이 코드 리뷰, 브랜치 완료 워크플로를 "제안이 아니라 의무"로 자동 트리거하도록 설계했고, Claude Code·Codex·Cursor·Gemini CLI·OpenCode 등 여러 에이전트 하네스에 각각 패키징해 배포합니다. 방법론 자체를 코드가 아니라 `SKILL.md` 파일과 검증 가능한 스킬 목록으로 응집시키는 접근이 핵심입니다.

## HKUDS/CLI-Anything

- <https://github.com/HKUDS/CLI-Anything>
- 언어: Python
- 오늘 스타: 744 (총 66,134)

GIMP, Blender, LibreOffice, Zotero, Godot 같은 기존 소프트웨어를 AI 에이전트가 다룰 수 있는 CLI로 자동 생성해주는 프로젝트입니다. 분석 → 설계 → 구현 → 테스트 계획 → 테스트 작성 → 문서화 → 퍼블리시로 이어지는 7단계 파이프라인을 거치며, "실제 소프트웨어를 그대로 호출한다 — 폴백도, 기능 저하도 없다"는 원칙 아래 헤드리스 LibreOffice나 Blender의 Python API 같은 실제 백엔드를 직접 불러씁니다. 생성된 각 CLI는 대화형 REPL과 스크립트용 서브커맨드를 함께 지원하고 모든 명령이 JSON 출력을 낼 수 있다는 점에서, GUI 전용 소프트웨어를 에이전트 친화적 인터페이스로 감싸는 구체적인 패턴을 볼 수 있습니다.

## jingyaogong/minimind

- <https://github.com/jingyaogong/minimind>
- 언어: Python
- 오늘 스타: 701 (총 71,483)

NVIDIA 3090 한 장으로 약 2시간, GPU 대여비 3위안 수준에 64M 파라미터급 LLM을 처음부터 훈련시키는 교육용 프로젝트입니다. 핵심 알고리즘을 전부 PyTorch로 바닥부터 구현해 고수준 라이브러리 뒤에 숨기지 않는 것을 원칙으로 삼고 있고, 8레이어·d_model 768의 디코더 전용 트랜스포머(Pre-Norm RMSNorm, SwiGLU, RoPE+YaRN)와 4-expert top-1 MoE 변형을 함께 제공합니다. 프리트레이닝부터 SFT, LoRA, distillation, DPO, RLAIF(PPO·GRPO·CISPO), 멀티턴 tool-use를 활용하는 agentic RL까지 LLM 학습 파이프라인 전체를 한 레포에서 끝까지 따라갈 수 있다는 점이 꾸준히 트렌딩에 오르는 이유로 보입니다.

## cursor/plugins

- <https://github.com/cursor/plugins>
- 언어: TypeScript
- 오늘 스타: 268 (총 19,695)

Cursor의 공식 플러그인 마켓플레이스 레포로, 개발 도구·생산성 앱·CRM/마케팅/금융 SaaS까지 아우르는 플러그인들을 모아둡니다. 각 플러그인은 레포 루트의 독립 디렉터리로 존재하면서 `skills/`(SKILL.md 기반 에이전트 스킬), `rules/`(`.mdc` 형식의 Cursor rule), `mcp.json`(MCP 서버 연결 정의)을 함께 갖추는 구조이고, 루트의 `marketplace.json`이 전체 목록을 관리합니다. 스킬·규칙·MCP 서버 연결을 하나의 매니페스트 형식으로 묶어 배포하는 방식을 구체적으로 보여주는 레포로, 에디터 생태계가 에이전트 확장 기능을 어떻게 표준화하는지 참고할 만합니다.

### infinityabundance/entropyfs

- <https://github.com/infinityabundance/entropyfs> · 언어: Rust · 스타: 57 · 생성일: 2026-08-25

FUSE로 마운트하는 Rust 기반 Linux 파일시스템으로, "논리적 바이트는 애플리케이션을 위한 인터페이스일 뿐, 영속화해야 할 본질이 아니다"는 전제에서 출발합니다. `X = Materialize(D)`, 즉 정확히 그 바이트를 재현할 수 있는 최소한의 엔트로피·설정 상태 `D`만 저장한다는 원칙을 rANS 엔트로피 코딩, 콘텐츠 주소 기반 CAS, copy-on-write B-tree 청크 인덱스로 구현했고, 압축 불가능한 데이터(난수·암호화된 데이터)는 그냥 원본 그대로 저장하는 쪽을 "실패가 아니라 성공 조건"으로 명시해둔 점이 특이합니다. crash-consistency 테스트 스위트, 적대적 입력에 패닉 대신 타입드 에러를 요구하는 hostile-media court, 21개 항목 릴리스 게이트 체크리스트, 그리고 Btrfs+zstd 대비 압축률과 fsync 지연 저하까지 솔직하게 공개한 성능 문서까지 갖춰, 과장 없이 자기 한계를 측정하고 기록하는 시스템 프로그래밍 레포의 좋은 예로 보입니다.

### taladb/taladb

- <https://github.com/taladb/taladb> · 언어: Rust · 스타: 117 · 생성일: 2026-03-25

"하나의 데이터베이스, 앱이 돌아가는 모든 곳에서"를 표방하는 임베디드 문서·벡터 데이터베이스입니다. Rust로 작성한 단일 엔진 코어를 WebAssembly(브라우저), napi-rs(Node.js), JSI·JNI·SwiftPM(React Native·Android·iOS·macOS) 바인딩으로 감싸는 구조이고, 저장은 redb 위에서 ACID 쓰기를 보장하며 브라우저에서는 OPFS(IndexedDB 폴백)를 씁니다. MongoDB 스타일 쿼리와 보조 인덱스, 코사인·내적·유클리드 거리의 exact k-NN과 선택적 HNSW 벡터 검색, BM25 기반 키워드 검색을 reciprocal rank fusion으로 결합한 하이브리드 검색까지 한 엔진에 담았습니다. 서버나 클라우드 왕복 없이 로컬에서 문서·벡터·전문 검색을 동시에 처리하는 구조를 여러 플랫폼에 동일하게 이식한 설계가 눈에 띄는 임베디드 DB 사례입니다.
