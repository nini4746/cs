### baseballyama/rsvelte

- <https://github.com/baseballyama/rsvelte>
- 언어: Rust
- 스타: 148 (2026-01-04 생성)

Svelte 5 공식 컴파일러를 Rust로 통째로 포팅해 OXC 툴체인에 네이티브로 끼워 넣는 프로젝트입니다. 파싱은 OXC의 파서와 메모리 효율적인 AST 표현(u32 스팬, 압축 문자열, arena 할당)에 위임하고, 분석·변환 단계를 공식 컴파일러와 동일한 3단계 파이프라인으로 재구현했습니다. 공식 컴파일러와 출력을 비교하는 3,500개 픽스처 스위트와 32개 실제 저장소에서 뽑은 13,200개 유닛의 회귀 테스트로 검증하며, M1 Pro 기준 클라이언트 컴파일 21.2배·포매팅 281.7배·린팅 54.4배 속도 향상을 벤치마크로 제시합니다. 대형 JS 생태계 컴파일러를 Rust로 재작성하면서 원본과의 출력 동등성을 어떻게 지속적으로 검증하는지 보여주는 좋은 사례입니다.

### pilot-protocol/pilotprotocol

- <https://github.com/pilot-protocol/pilotprotocol>
- 언어: Go
- 스타: 128 (2026-02-07 생성)

AI 에이전트를 위한 탈중앙 네트워크 인프라로, 각 에이전트에 영구 주소를 부여하고 중개자 없이 직접 암호화된 P2P 메시징을 하게 해줍니다. 로컬 데몬(Unix 소켓)이 암호화·NAT 통과·혼잡 제어를 담당하고, Ed25519 키 교환과 AES-256-GCM 암호화 위에 슬라이딩 윈도우·SACK·AIMD 혼잡 제어를 갖춘 UDP 터널을 데몬 간에 직접 맺는 구조이며, 실패 시 종단간 암호화를 유지한 채 비콘 릴레이로 우회합니다. Go 표준 라이브러리만으로 구현했고 `go test`로 1,048개 테스트를 통과시키며, 프로토콜을 IETF Internet-Draft로 표준화까지 추진하고 있어 TCP 유사 전송 신뢰성과 P2P NAT 통과를 로우레벨에서 공부하기 좋습니다.
