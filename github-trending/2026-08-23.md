- <https://github.com/AprilNEA/OpenLogi>
- 언어: Rust
- 오늘 스타: 1,008 (총 14,537)

Logitech Options+의 오픈소스 대체제로, 계정 로그인이나 원격 측정 없이 로지텍 주변기기를 로컬에서 직접 제어하는 것을 목표로 합니다.
