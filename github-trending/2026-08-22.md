오늘 트렌딩은 에이전트 스킬·하니스 생태계가 계속 몸집을 불리는 흐름과, 그 주변 인프라를 다루는 프로젝트들이 함께 등장하는 하루입니다. affaan-m/ECC가 68개 서브에이전트와 286개 스킬을 하나로 묶은 "에이전트 하니스 운영체제"를 내세우며 여전히 압도적인 누적 스타를 유지했고, 어제 상위권이었던 mattpocock/skills·obra/superpowers도 나란히 자리를 지켰습니다. 그 옆에서 OpenAI가 로컬 실행형 코딩 에이전트 Codex CLI를 새로 공개했고, Wei-Shaw/sub2api는 여러 AI 구독의 API 쿼터를 한 게이트웨이로 모아 재분배하는 인프라를 내놓으면서 "에이전트를 어떻게 실행·인증·과금할 것인가"라는 질문에 답하고 있습니다. 그 사이 makeplane/plane 같은 프로젝트 관리 도구가 꾸준히 오르는 것은, 에이전트 생태계 밖에서도 팀 협업 도구 수요가 여전히 크다는 신호로 보입니다.

## openai/codex

- <https://github.com/openai/codex>
- 언어: Rust
- 오늘 스타: 4,159 (총 112,410)

OpenAI가 만든 로컬 실행형 코딩 에이전트로, CLI·IDE 확장(VS Code, Cursor, Windsurf)·데스크톱 앱 등 여러 접점으로 제공됩니다. ChatGPT Plus/Pro/Business/Enterprise 계정으로 인증하거나 API 키로 대체 로그인할 수 있고, macOS(Apple Silicon/x86_64)·Linux(x86_64/arm64)·Windows용 설치 바이너리를 releases.openai.com에서 배포하되 실패 시 GitHub Releases로 자동 폴백하는 구조를 갖췄습니다. Apache-2.0으로 공개된 만큼, 클라우드 종속 없이 로컬에서 도는 에이전트 CLI를 어떤 배포·인증 구조로 설계하는지 참고하기 좋습니다.

"계획→테스트→구현→리뷰→검증→기억→개선"이라는 절차를 매 프롬프트마다 반복 입력하는 대신 한 번 설치해 재사용하도록 설계했고, 하니스 설정의 인젝션 위험을 감사하는 AgentShield 같은 보안 스캐너도 포함합니다. 2026년 1~2월 사이 3주 만에 6만8천 스타를 모은 이례적인 증가 속도가 특징이며, 오늘도 총 24만 스타를 넘기며 상위권에 남아 있습니다.

- 언어: C++
