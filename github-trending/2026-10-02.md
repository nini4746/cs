오늘 GitHub 트렌딩은 "에이전트가 할 수 있는 일의 범위를 넓히는" 도구들이 상위권을 채운 하루입니다. 트위터·레딧·유튜브·빌리빌리까지 유료 API 없이 읽어오게 해주는 Agent-Reach가 1위에 올랐고, 바로 아래에서 에이전트 응답과 도구 결과를 압축해 토큰 비용을 줄이는 caveman, TDD 기반 개발 방법론 전체를 스킬로 강제하는 superpowers, "AI 티 나는" 디자인을 걸러내는 impeccable, 평범한 HTML을 비디오로 렌더링하는 hyperframes가 나란히 올랐습니다. 접근 범위 확장, 비용 절감, 작업 방법론, 결과물 품질, 새로운 출력 형식까지 — 에이전트 생태계가 여러 방향에서 동시에 성숙해지고 있다는 인상을 주는 하루입니다.

## Panniantong/Agent-Reach

- <https://github.com/Panniantong/Agent-Reach>
- 언어: Python
- 오늘 스타: 683 (총 약 88,100)

AI 에이전트에게 트위터/X, 레딧, 유튜브, GitHub, 빌리빌리, 샤오홍슈를 읽고 검색할 수 있는 능력을 하나의 CLI로 묶어주는 도구입니다. 플랫폼마다 "1차 백엔드 실패 시 2차 백엔드로" 자동 전환하는 구조(예: 유튜브는 yt-dlp, 트위터는 twitter-cli 실패 시 OpenCLI, 빌리빌리는 6월 yt-dlp 차단 이후 bili-cli로 교체)를 쓰는 것이 핵심이며, 공식 유료 API 대신 브라우저 로그인 세션(쿠키)을 활용해 비용 없이 접근하는 대신 계정 정지 위험을 감수하는 철학을 명시하고 있습니다. 자격증명은 로컬 600 권한 파일에만 보관하고 Agent-Reach 자신은 특정 구현 위의 "한 단계 위 선택·설치·진단 계층"이라고 스스로를 규정하는데, 접근 방식이 계속 바뀌는 플랫폼들을 에이전트가 안정적으로 쓰게 만들려면 백엔드를 프로브하고 교체하는 레이어가 왜 필요한지 보여주는 사례입니다.

## JuliusBrussee/caveman

- <https://github.com/JuliusBrussee/caveman>
- 언어: Go
- 오늘 스타: 271 (총 약 108,900)

에이전트가 주고받는 입출력 토큰을 압축해 비용을 줄이는 도구 모음으로, 응답 문장을 규칙 기반으로 줄이는 스킬, 요청과 응답 사이에서 JSON·로그·diff·테스트 출력을 압축하는 로컬 프록시(Go), SDK 호출을 감싸는 TypeScript/Python 미들웨어 세 부분으로 구성됩니다. 원본은 항상 로컬 SQLite에 복구 가능한 핸들과 함께 보관하고 보안 경고나 에러 메시지 전체 문장은 절대 건드리지 않는다는 원칙을 지키면서도, Adobe Research 벤치마크에서 모델당 1.4~2.4배(최대 3배) 비용 절감, JetBrains 86개 실제 코딩 태스크에서 품질 저하 없이 출력 토큰 8.5% 감소, 54회 Claude Code 테스트에서 입력 토큰 33.2% 감소(18/18 정답 유지)라는 구체적 수치를 공개하고 있습니다. 압축이 오히려 토큰을 늘린 사례(HTML alert, +9.9%)까지 솔직하게 보고하는 점에서, "에이전트를 더 똑똑하게"가 아니라 "더 싸게" 만드는 흐름이 데이터로 뒷받침되고 있음을 보여줍니다.

### geastack/compiler

- <https://github.com/geastack/compiler>
- 언어: TypeScript
- 스타: 53 (생성일: 2026-09-19)

TypeScript를 C++로 선행 컴파일(AOT)해 JavaScript 엔진 없이 ESP32·RP2350 같은 마이크로컨트롤러부터 데스크톱·모바일·콘솔·서버까지 네이티브 바이너리로 돌리는 컴파일러 `geatsc`입니다. 타깃 중립적인 프런트엔드(semantics) → 물리적 표현을 다루는 representation → 동적 변환 능력을 다루는 conversion → 파이프라인 전체를 사전 점검하는 preflight → SSA 기반 타입드 IR → C++ 코드 생성(targets/cpp)으로 이어지는 계층형 파이프라인을 두고, semantics 레이어 아래로는 원본 TypeScript AST에 아예 접근할 수 없도록 경계를 강제합니다. "결정은 파일명이나 경로, 소스 텍스트에 의존하지 않는다", "정적 타입은 네 가지 예외를 빼면 절대 박싱하지 않는다", "제약이 깨지면 느슨하게 넘어가지 않고 닫힌 채로 실패한다"는 세 가지 설계 원칙을 `scripts/architecture.mjs`라는 별도 게이트 스크립트로 코드베이스 전체에 구조적으로 강제하고 있다는 점에서, 설계 철학을 문서로만 남기지 않고 빌드 과정에 직접 박아 넣은 점이 인상적이었습니다.
