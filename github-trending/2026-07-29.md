Vitest 단위 테스트와 Playwright 브라우저 종단 테스트를 함께 갖췄고 아키텍처 문서도 상세해, 고전 언어의 파서·실행기를 밑바닥부터 구현하면서 테스트까지 챙긴 보기 드문 사례입니다.

### confh/Tiny

- <https://github.com/confh/Tiny>
- 언어: Go
- 스타: 57 (2026-05-07 생성)

동적 타입에 선택적 타입 힌트를 얹은 프로그래밍 언어로, 바이트코드로 컴파일되어 자체 구현한 동시성 가상머신 위에서 실행됩니다. 슬롯 기반 지역 변수를 쓰는 스택 기반 VM에 인터프리터와 JIT 컴파일러를 함께 두어, 반복문이 뜨거워지면 자동으로 감지해 최적화하는 "region outlining" 기법을 구현했고, 이벤트 루프가 아닌 OS 스레드 기반의 `spawn` 키워드로 진짜 병렬 실행을 지원합니다. WebAssembly로 네이티브 Go 확장과 JIT 산출물을 내보낼 수 있는 점, 그리고 언어 스펙부터 동시성 모델까지 다루는 별도 문서 사이트를 운영하는 점에서, 바이트코드 VM과 JIT을 직접 설계해보려는 사람이 참고할 만한 프로젝트입니다.
