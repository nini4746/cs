오늘 트렌딩은 에이전트를 위한 생태계 도구들이 여전히 상위권을 채우는 가운데, 로컬·온디바이스 AI 모델 최적화라는 주제가 다시 두드러지는 하루입니다. Cursor의 공식 플러그인 마켓플레이스(cursor/plugins)와 어제에 이어 다시 오른 다이어그램 스킬(diagram-design)은 "에이전트에게 도구와 취향을 미리 장착시킨다"는 흐름을 보여주고, 온디바이스 파운데이션 모델(needle)과 로컬 파인튜닝을 가속하는 unsloth가 나란히 오른 것은 값비싼 클라우드 GPU 없이도 모델을 다루고 싶어하는 수요가 꾸준하다는 신호로 읽힙니다. 여기에 "시공간적 조합 가능성"을 표방하는 Node.js 메타 프레임워크(cordis)가 1위에 오르며, 플러그인 아키텍처 설계 자체에 대한 관심도 여전함을 보여줍니다.

## cordiverse/cordis

- <https://github.com/cordiverse/cordis>
- 언어: TypeScript
- 오늘 스타: 616 (총 3,834)

"시공간적 조합 가능성(Spatiotemporal Composability)"을 내세우는 Node.js 메타 프레임워크로, 플러그인과 서비스를 동적으로 등록·해제할 수 있는 구조를 핵심으로 합니다. 아직 API가 안정화되지 않았다고 명시할 만큼 초기 단계지만, 이 설계를 다룬 별도의 연구 논문까지 공개되어 있어 단순한 유틸리티 라이브러리를 넘어 이론적 기반을 갖춘 프레임워크로 보입니다. 의존성 주입과 생명주기 관리를 함께 다루는 메타 프레임워크를 어떻게 설계하는지 참고하기 좋은 프로젝트입니다.

## cursor/plugins

- <https://github.com/cursor/plugins>
- 언어: TypeScript
- 오늘 스타: 152 (총 2,888)

Cursor 에이전트를 위한 공식 플러그인 마켓플레이스 레포입니다. 플러그인마다 `plugin.json` 매니페스트로 표준화된 디렉터리를 두고, 에이전트가 실행할 워크플로를 정의하는 `SKILL.md`, Cursor 전용 규칙 파일, 원격 MCP 서버 설정을 함께 묶는 구조입니다. Salesforce, HubSpot, Google Workspace 같은 외부 서비스를 대부분 호스티드 MCP 서버를 통해 연동해, 자격증명을 플러그인에 직접 담지 않고도 여러 플러그인을 조합할 수 있게 설계한 점이 특징입니다.
