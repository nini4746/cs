## alibaba/open-code-review

- <https://github.com/alibaba/open-code-review>
- 언어: Go
- 오늘 스타: 2,751 (총 27,600)

Git diff를 읽어 변경된 파일을 LLM 에이전트에 보내고 라인 단위로 정밀한 리뷰 코멘트를 생성하는 CLI 도구로, 어제에 이어 오늘도 스타가 가장 크게 늘었습니다. 파일 선정·번들링·규칙 매칭처럼 정확도가 중요한 단계는 결정론적 로직으로 고정하고 판단이 필요한 부분만 에이전트에 맡기는 하이브리드 구조가 핵심이며, 프로덕션 데이터로 다듬은 전용 프롬프트 덕분에 범용 에이전트 대비 약 1/9의 토큰만으로도 더 높은 정밀도를 낸다고 밝히고 있습니다. "에이전트에게 무엇을 맡기고 무엇을 하드 룰로 고정할지"를 코드 리뷰라는 구체적 도메인에서 어떻게 나누는지 참고하기 좋은 사례입니다.

## debpalash/VoiceStudio

- <https://github.com/debpalash/VoiceStudio>
- 언어: Python
- 오늘 스타: 2,081 (총 30,429)

ElevenLabs 같은 상용 음성 서비스의 로컬 대안을 표방하며 목소리 클로닝·영상 더빙·받아쓰기·장문 오디오 제작을 자체 하드웨어에서 처리하는 프로젝트로, 사흘째 트렌딩 상위권을 유지하고 있습니다. Tauri v2(Rust) 데스크톱 셸과 React+Vite UI, FastAPI 백엔드가 로컬호스트 HTTP/WebSocket으로 통신하고, 16개 TTS 엔진과 11개 ASR 엔진을 교체 가능한 레지스트리로 묶어 자유롭게 조합할 수 있게 했습니다. 646개 언어를 지원하면서도 프로젝트·음성·출력물이 기본적으로 로컬에만 남고 합성 음성에 AudioSeal 워터마킹을 기본 적용한다는 점에서, 로컬 우선 설계와 생성물 오남용 방지를 동시에 고민한 흔적이 보입니다.

## JustVugg/colibri

- <https://github.com/JustVugg/colibri>
- 언어: C
- 오늘 스타: 2,035 (총 33,253)

7B부터 2.8T 파라미터급까지 여러 모델 계열을 소비자 하드웨어에서 돌리기 위한 추론 엔진으로, 며칠째 트렌딩에 머무르며 꾸준히 스타가 붙고 있습니다. VRAM·RAM·NVMe를 하나의 메모리 계층으로 다루는 "weight JIT" 전략이 핵심으로, dense 레이어는 int4로 양자화해 RAM에 상주시키고 수만 개에 달하는 routed expert는 디스크에 두었다가 라우터가 다음 레이어에서 필요한 expert를 높은 정확도로 미리 예측해 prefetch합니다. Python 런타임 없이 모델 계열마다 C 파일 하나로 구현된 순수 C 코드베이스라는 점도, 추론 엔진을 밑바닥부터 설계할 때 참고할 만한 지점입니다.

## Homebrew/BrewUI

- <https://github.com/Homebrew/BrewUI>
- 언어: Swift
- 오늘 스타: 388 (총 1,133)

macOS 패키지 관리자 Homebrew의 공식 GUI로, CLI에 익숙하지 않은 사용자도 안전하게 패키지를 탐색·설치·업데이트·관리할 수 있게 해줍니다. Swift 6.0과 SwiftUI로 작성됐고, `brew` CLI와 Homebrew의 JSON API를 데이터 소스로 삼으며, 셸 시작 파일을 비활성화하고 최소 PATH만 남긴 `/bin/zsh`를 통해 Homebrew 실행을 격리하는 등 예측 가능한 동작을 위한 구조적 장치를 갖추고 있습니다. CLI 도구가 지배적인 생태계에서 투명성을 유지하면서도 접근성을 높인 공식 GUI라는 점에서, 오랫동안 커맨드라인 전용이었던 도구에 GUI 계층을 어떻게 얹는지 살펴보기 좋은 사례입니다.
