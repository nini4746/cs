## TauricResearch/TradingAgents

- <https://github.com/TauricResearch/TradingAgents>
- 언어: Python
- 오늘 스타: 1,376 (총 115,508)

LangGraph로 오케스트레이션되는 멀티에이전트 프레임워크로, 실제 트레이딩 데스크의 의사결정 과정을 시뮬레이션합니다. 펀더멘털·감성·뉴스·기술 분석을 맡는 애널리스트 팀이 병렬로 리포트를 내면, 낙관·비관 입장의 리서처가 토론을 벌이고, 트레이더가 타이밍과 규모를 결정한 뒤 리스크 팀과 포트폴리오 매니저가 승인 여부를 가립니다. SEC EDGAR 공시일 기준으로 데이터를 끊어 미래 참조(look-ahead bias)를 막고, 과거 결정을 실현 수익과 대조해 반성(reflection)을 생성하는 메모리 로그, 백테스팅 그리드까지 갖춘 것을 보면, LLM 에이전트에게 실제 자산 운용 의사결정을 맡길 때 재현성과 리스크 관리를 어떻게 구조적으로 설계하는지 참고할 만한 프로젝트입니다.
