오늘 트렌딩은 "에이전트를 둘러싼 안전장치"라는 주제가 상위권을 채운 하루입니다. 코드 리뷰를 대신하는 에이전트(open-code-review)와 그 에이전트가 만든 코드의 보안을 감사하는 스킬(security-audit-skill)이 나란히 오르면서, 에이전트가 작성한 코드를 다시 에이전트가 검증하는 이중 구조가 일상화되는 흐름이 보입니다. 여기에 소비자 하드웨어에서 초거대 MoE 모델을 돌리는 추론 엔진(colibri), macOS 생산성 도구, 로컬 우선 음성 AI 스튜디오까지 겹치면서, 개발 도구·시스템 최적화·프라이버시 중심 AI라는 세 갈래가 동시에 눈에 띕니다.

## alibaba/open-code-review

- <https://github.com/alibaba/open-code-review>
- 언어: Go
- 오늘 스타: 3,215 (총 30,830)

Git diff를 분석해 라인 단위로 정밀한 리뷰 코멘트를 생성하는 AI 코드 리뷰 CLI입니다. 파일 선정·번들링·코멘트 위치 지정 같은 부분은 결정론적 로직으로 처리하고, 맥락 파악과 판단이 필요한 부분만 LLM 에이전트에게 맡기는 "결정론+에이전트 하이브리드" 구조가 핵심입니다. 원래 알리바바 내부에서 수만 명의 개발자가 쓰던 도구를 오픈소스화한 것으로, 벤치마크에서는 범용 코딩 에이전트보다 적은 토큰으로 더 높은 정밀도를 낸다고 밝히고 있습니다. "LLM에게 무엇을 결정론적으로 주고 무엇을 맡길지"를 나누는 설계를 배우기 좋은 사례입니다.

## cloudflare/security-audit-skill

- <https://github.com/cloudflare/security-audit-skill>
- 언어: JavaScript
- 오늘 스타: 1,249 (총 6,034)

정찰 → 커버리지 기반 탐색 → 후보 검증 → 구조화된 출력 → 독립 검증 → 중립적 리포트의 6단계로 보안 감사를 자동화하는 코딩 에이전트용 스킬입니다. 특히 "찾는 에이전트와 검증하는 에이전트를 분리한다"는 적대적 검증 철학이 눈에 띄는데, 찾아낸 취약점을 처음 본 별도 에이전트가 다시 검증하게 해 거짓 양성을 줄이는 구조입니다. 커버리지 원장과 findings 데이터베이스를 JSON으로 관리해 여러 번 돌려도 이전 감사와 중복 없이 빈틈만 채우도록 설계한 점도, 반복 가능한 보안 감사 파이프라인을 설계할 때 참고할 만합니다.

## JustVugg/colibri

- <https://github.com/JustVugg/colibri>
- 언어: C
- 오늘 스타: 1,532 (총 34,697)

7,440억~2.8조 파라미터급 MoE 모델을 전용 GPU 없는 소비자 하드웨어에서 돌리는 순수 C 추론 엔진입니다. 디스크·RAM·VRAM을 하나의 메모리 계층으로 취급하고, 레이어별 LRU 캐시, 자주 쓰는 전문가(expert)를 빠른 계층에 학습적으로 고정하는 기법, 한 레이어 앞서 미리 읽어오는 프리페칭으로 디스크 I/O 지연을 숨기는 구조를 씁니다. 외부 의존성 없이 순수 C로 짜인 점과, 모델 가중치를 "빠른 메모리에 다 올려야 하는 것"이 아니라 "계층별로 스테이징하는 데이터"로 보는 발상 자체가, 거대 모델을 제한된 하드웨어에 맞추는 엔지니어링 사례로 공부할 가치가 있습니다.

### swapnil404/mineSQL

- <https://github.com/swapnil404/mineSQL>
- 언어: Go
- 스타: 33 (2026-06-04 생성)

Postgres 호환 SQL을 마인크래프트 월드에 저장하는 장난스러운 프로젝트지만, 안을 들여다보면 WAL, MVCC, 쿼리 실행기, SQL 파서까지 갖춘 진짜 데이터베이스 엔진이 Go로 구현돼 있습니다. INT·BOOLEAN 컬럼은 문장(紋章) 블록으로, TEXT 컬럼은 표지판으로, 트랜잭션 로그는 강연대 책으로 인코딩하고, Paper 플러그인이 TCP로 Go 엔진과 마인크래프트 월드를 연결하는 구조입니다. 테이블은 스폰에서 동쪽으로, 트랜잭션은 서쪽으로, 메타데이터는 지하에 배치해 월드 자체를 쿼리 가능하게 만든 발상이 재미있는데, 겉보기의 장난스러움과 달리 WAL·MVCC 같은 실제 DB 내부 구조를 처음부터 구현해봤다는 점에서 데이터베이스 엔진 공부용으로 눈여겨볼 만합니다.
