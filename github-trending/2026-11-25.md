오늘 트렌딩은 "에이전트에게 무엇을 스킬로 장착시킬 것인가"라는 주제가 상위권을 거의 독점한 하루입니다. 레드팀/버그헌팅 스킬 번들(Claude-BugHunter), 범용 개발 방법론 스킬 프레임워크(superpowers), 전문 소프트웨어를 CLI로 감싸 에이전트가 쓰게 만드는 생성기(CLI-Anything)가 나란히 오르면서, 코딩 에이전트의 능력을 코드가 아니라 스킬 파일·CLI·방법론 형태로 패키징하는 흐름이 뚜렷합니다. 그 사이에서 64M 파라미터 LLM을 두 시간 안에 처음부터 훈련시키는 교육용 프로젝트(minimind)가 여전히 꾸준히 인기를 끌고, Cursor의 공식 플러그인 마켓플레이스(cursor/plugins)도 생태계 확장의 한 축으로 트렌딩에 올랐습니다.

- 언어: Python
- 오늘 스타: 1,644 (총 22,463)

Claude Code를 버그 헌팅·외부 레드팀 어시스턴트로 바꿔주는 스킬 번들로, 84개 스킬과 15개 슬래시 명령을 4계층(방법론/마인드셋, HackerOne 공개 리포트 기반 58개 취약점 클래스별 헌팅 스킬, M365/Entra·Okta·vCenter·VPN 어플라이언스 같은 엔터프라이즈 공격 체인, 트리아지/리포팅/증거 관리)으로 구성했습니다. 플러그인 설치나 설정 디렉터리 복사 모두 지원하고 `cbh` CLI 러너와 Burp MCP 연동도 포함돼 있는데, README가 내부 AD 공격·C2·포스트 익스플로잇·에바전은 명시적으로 범위에서 제외한다고 밝힌 점이 눈에 띕니다. 에이전트에게 공격 기법 자체보다 "언제 어떤 스킬을 자동으로 불러올지"의 트리거 설계를 어떻게 하는지 참고하기 좋은 사례입니다.

## obra/superpowers

- <https://github.com/obra/superpowers>
- 언어: Shell
- 오늘 스타: 902 (총 326,338)

조합 가능한 skill과 이를 자동으로 쓰게 만드는 bootstrap 지침으로 구성된, 코딩 에이전트용 소프트웨어 개발 방법론입니다. 디자인 브레인스토밍 → git worktree 생성 → 상세 계획 작성 → subagent 또는 인라인 실행 → TDD·코드 리뷰·브랜치 완료로 이어지는 워크플로를 스킬이 자동으로 트리거하도록 설계했고, Claude Code, Codex, Cursor, Gemini CLI, OpenCode 등 여러 하네스를 각각 별도 설치로 지원합니다. `SKILL.md` 파일 중심의 스킬 라이브러리와 자체 `superpowers-evals` 드릴 하네스로 스킬의 행동 자체를 테스트하는 구조가 특징으로, 방법론을 코드가 아니라 "검증 가능한 스킬 세트"로 응집시키는 접근을 공부하기 좋습니다.

## HKUDS/CLI-Anything

- <https://github.com/HKUDS/CLI-Anything>
- 언어: Python
- 오늘 스타: 1,094 (총 65,441)

AI 에이전트가 GIMP, Blender, LibreOffice, Zoom 같은 전문 소프트웨어를 직접 제어할 수 있도록 CLI를 자동 생성하는 프로젝트입니다. 소스코드 분석 → 명령 구조 설계 → Click 기반 CLI 구현 → 테스트 설계·작성 → 설치 가능한 Python 패키지 퍼블리시로 이어지는 7단계 파이프라인을 거치며, 생성된 CLI는 상태를 유지하는 REPL과 스크립트용 서브커맨드를 모두 지원하고 `--json` 출력도 제공합니다. 소프트웨어의 동작을 흉내 내는 대신 헤드리스 LibreOffice나 Blender 같은 실제 애플리케이션 백엔드를 그대로 호출하는 방식이라, GUI 전용 소프트웨어를 에이전트 친화적인 인터페이스로 감싸는 구체적인 방법을 볼 수 있습니다. `CLI-Hub`라는 pip 설치형 패키지 매니저로 커뮤니티가 만든 CLI를 설치·탐색할 수 있다는 점도 생태계 확장 전략으로 참고할 만합니다.

## jingyaogong/minimind

- <https://github.com/jingyaogong/minimind>
- 언어: Python
- 오늘 스타: 828 (총 70,812)

64M 파라미터급 LLM을 RTX 3090 한 장으로 두 시간 안에, GPU 대여비 약 3위안 수준으로 처음부터 훈련시키는 프로젝트입니다. MoE 아키텍처, 데이터 준비, 프리트레이닝, SFT, LoRA, DPO, RLAIF(PPO·GRPO·CISPO), 툴 사용, 에이전틱 RL, 적응적 사고, distillation까지 LLM 학습 파이프라인 전체를 다루면서 핵심 알고리즘을 고수준 라이브러리 래퍼 없이 직접 구현한 것이 핵심입니다. 아키텍처는 Qwen3 계열을 따라 pre-norm RMSNorm, SwiGLU, RoPE+YaRN 확장, 6,400 토큰 커스텀 토크나이저를 쓰고, 학습이 끝난 모델은 transformers·llama.cpp·vLLM·Ollama로 바로 내보낼 수 있습니다. LLM 내부 구조를 처음부터 끝까지 직접 구현해보고 싶을 때 참고할 교육용 레퍼런스로 계속 트렌딩에 오르는 이유를 알 만합니다.

## cursor/plugins

- <https://github.com/cursor/plugins>
- 언어: TypeScript
- 오늘 스타: 408 (총 19,449)

Cursor의 공식 플러그인 마켓플레이스 레포로, 100개가 넘는 플러그인이 등록돼 있습니다. 각 플러그인은 레포 루트의 자체 디렉터리에 `.cursor-plugin/plugin.json` 매니페스트를 가지고, 루트의 `marketplace.json`이 전체 목록을 관리하는 구조입니다. 개발자 도구(코드 리뷰, CI, 에이전트 오케스트레이션, CLI 설계), 생산성, 통합(Google Workspace·GitHub·Salesforce 등 CRM/금융/마케팅 플랫폼), 금융·법률, 유틸리티로 카테고리가 나뉘어 있고, 플러그인 디렉터리 안에는 `SKILL.md`, Cursor rule(`.mdc`), MCP 서버 연결용 `mcp.json`이 함께 들어갈 수 있습니다. 하나의 에디터 생태계가 스킬·규칙·MCP 서버를 한 매니페스트 형식으로 묶어 배포하는 방식을 구체적으로 볼 수 있는 레포입니다.

### 0x00-Community/j8

- <https://github.com/0x00-Community/j8>
- 언어: Rust · 스타: 8 · 생성일: 2026-11-14

V8의 아키텍처를 그대로 본뜬 Rust 기반 JavaScript 엔진입니다. `eval`과 `Function`을 포함한 모든 JS를 V8 Ignition 바이트코드로 컴파일하고, JIT 티어가 핫 함수와 루프를 SSA 그래프로 변환해 x86-64·AArch64 네이티브 코드를 직접 방출하는 구조를 갖췄습니다. 힙은 같은 조직이 만든 별도 GC인 paragc 위에 올렸고 파싱은 oxc를 쓰며, 프레임워크·바이트코드·컴파일러·실행기·JIT·빌트인·플랫폼·바인딩·Node-API·태스크큐로 역할을 쪼갠 크레이트 구조를 취합니다. test262 기준 42,500개 테스트 통과를 CI에서 회귀 실패로 강제하고 interpreter·JIT 양쪽 모드로 돌릴 수 있다고 밝히며, V8 대비 벤치마크(jitless 0.4배, JIT 1.1배)까지 공개한 점에서 생성 2주가 안 된 레포임에도 검증 수준이 상당히 높다고 판단했습니다.

### 0x00-Community/paragc

- <https://github.com/0x00-Community/paragc>
- 언어: Rust · 스타: 5 · 생성일: 2026-11-16

여러 스레드가 힙 하나를 공유하는 Rust용 병렬 가비지 컬렉터로, 32KiB 블록을 256B 라인으로 나눈 Immix 스타일 mark-region 레이아웃과 스레드별 범프 할당 버퍼, 뮤텍스 없는 워크 스틸링 마크·스윕을 사용합니다. stop-the-world 구간을 `&mut Heap`을 받는 함수로 설계해 Rust의 borrow checker 자체가 배타적 접근을 강제하도록 만들어 별도의 세이프포인트나 스택 스캐닝이 필요 없다고 설명하며, SATB write barrier 기반 concurrent marking, lazy/concurrent sweeping, 기회적 evacuation, young-gen 컬렉션, 구세대 레퍼런스 카운팅까지 갖췄습니다. 각 서브시스템의 설계 근거, 안전성 규칙, 수십 개 명명된 테스트를 구체 동작에 매핑한 검증표, Miri의 Stacked/Tree Borrows 모드 실행 결과까지 README에 명시돼 있어 문서화·검증 수준이 눈에 띄게 높고, 바로 위 j8 JS 엔진이 이 GC를 힙으로 쓰고 있다는 점에서 같은 조직이 엔진과 GC를 나란히 바닥부터 쌓아 올리는 모습을 함께 볼 수 있습니다.

### ArneCode/marser

- <https://github.com/ArneCode/marser>
- 언어: Rust · 스타: 39 · 생성일: 2026-03-23

유용한 에러 메시지, 에러 복구, 성능에 초점을 맞춘 Rust용 PEG 스타일 파서 컴비네이터 라이브러리입니다. `&str`와 `&[u8]`/`&[T]` 입력 모두에 대해 zero-copy 파싱을 지원하고 `Input` 트레이트를 구현하면 다른 입력 포맷에도 적용할 수 있으며, `capture!` 매크로로 매처와 결과 구성용 Rust 표현식을 짝지어 파서를 만들고 `bind!`/`bind_slice!`로 매칭된 값에 이름을 붙이는 구조입니다. 기본적으로 에러 복구 없이 먼저 파싱을 시도하고 실패할 때만 복구·진단 경로로 재시작하기 때문에 JSON 벤치마크 기준 평상시 오버헤드가 작다고 설명합니다. 가이드 문서, docs.rs API 문서, 그래머 변환기, 디자인 블로그 글, 실행 가능한 JSON·미니 언어 예제까지 문서화는 꼼꼼하지만, README 스스로 코드·문서·테스트 일부를 AI 도구로 초안 작성해 메인테이너가 리뷰했다고 밝히고 테스트 커버리지는 따로 설명하지 않는다는 점은 그대로 밝혀둡니다.
