## tester-army/e2e

- 언어: TypeScript
- 오늘 스타: 344 (총 2,601)

자연어로 "무엇을 테스트할지" 적으면 AI 에이전트가 웹은 Playwright(Chromium/Firefox/WebKit), 모바일은 별도 에이전트-디바이스 엔진으로 직접 화면을 조작해 로케이터와 어서션으로 결과를 검증하는 e2e 테스트 프레임워크입니다. 핵심은 "에이전트가 한 번 수행한 스텝을 이후 어서션이 검증하면, 다음 실행부터는 그 행동을 그대로 리플레이한다"는 구조로, 매번 LLM 추론 비용을 들이지 않고도 자연어 테스트를 결정론적인 자동화 테스트처럼 재사용할 수 있게 만든 점이 특징입니다. pnpm 워크스페이스 기반 모노레포로 코어 SDK·웹 엔진·모바일 엔진을 분리했고 커스텀 모델 제공자(자체 API 키나 로컬 모델)도 지원하는데, "자연어 테스트 작성"과 "안정적인 CI 재현성"이라는 상충하는 목표를 리플레이 캐싱으로 절충한 설계를 참고하기 좋습니다.

## caddyserver/caddy

- <https://github.com/caddyserver/caddy>
- 언어: Go
- 오늘 스타: 31 (총 76,351)

기본값으로 자동 HTTPS를 적용해 인증서 관리를 사실상 없애버린 멀티플랫폼 HTTP/1-2-3 웹 서버입니다. "앱"을 모듈로 구현하는 플러그인 아키텍처가 핵심이며, 네이티브 설정은 JSON이지만 Caddyfile·YAML·TOML·NGINX 설정까지 어댑터로 변환해 쓸 수 있고, REST API로 재시작 없이 설정을 갱신할 수 있습니다. libc에도 의존하지 않을 만큼 외부 의존성을 최소화한 Go 구현체로 이미 수조 건의 요청과 수백만 개의 TLS 인증서를 프로덕션에서 처리해왔다고 밝히는데, "보안 기본값(secure by default)"을 설정 파일 수준이 아니라 서버 자체의 설계 철학으로 삼은 사례로 참고할 만합니다.
