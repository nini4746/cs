GPU 인프라를 통째로 관리하는 플랫폼(dsx-ai-factory/nvke), 여러 에이전트를 메신저 연락처처럼 운용하는 데스크톱 앱(milind-soni/OpenMausBot), Claude API 위에서 바로 가져다 쓸 수 있는 스타터 모음(anthropics/claude-quickstarts), 셸 명령 한 줄로 브라우저를 조작하는 CLI(vercel-labs/agent-browser)까지, 에이전트를 둘러싼 레이어가 인프라·UX·SDK·실행 도구로 고르게 나뉘어 있습니다. 그 사이에서 10년 넘게 자리를 지켜온 OSINT 도구 Sherlock이 하루 만에 2,000개가 넘는 스타를 받으며 1위에 오른 것도 눈에 띄는데, 에이전트 생태계가 아무리 커져도 "사용자명 하나로 사람을 추적한다"는 고전적인 보안·프라이버시 주제가 여전히 폭발적인 관심을 끈다는 신호로 보입니다.

## dsx-ai-factory/nvke

- <https://github.com/dsx-ai-factory/nvke>
- 언어: Go
- 오늘 스타: 345

NVIDIA GPU 인프라 위에 격리된 Kubernetes 클러스터를 찍어내고 운영해주는 매니지먼트 플레인입니다. 임시 시드 클러스터가 먼저 매니지먼트 클러스터를 부트스트랩하고, 그 매니지먼트 클러스터가 NICo(NVIDIA Infra Controller)를 통해 GPU 머신을 프로비저닝해 각자 고유한 컨트롤 플레인·etcd·노드 풀을 가진 워크로드 클러스터 여러 개를 찍어내는 2단 구조로 되어 있습니다. 노드가 조인 자격을 받기 전에 TPM 기반 SPIFFE/SPIRE로 신원을 증명하게 하고 클러스터별 etcd 암호화를 제공하는 식으로 보안도 신경 썼지만, 아직 프리뷰 단계라 API 인증이 기본적으로 꺼져 있고 매니지먼트 클러스터 자체의 업그레이드·백업 절차는 문서화되어 있지 않다고 스스로 밝히고 있습니다. GPU 클라우드를 멀티테넌트로 쪼개 운영하려는 사람에게는 Cluster API 기반의 관리 클러스터/워크로드 클러스터 분리 패턴을 구체적으로 볼 수 있는 자료입니다.
