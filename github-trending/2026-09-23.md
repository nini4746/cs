## google/ax

- <https://github.com/google/ax>
- 언어: Go
- 오늘 스타: 1,542 (총 8,575)

"클러스터에서 수십억 개의 자율 에이전트 워크로드를 돌린다"는 목표를 내건 Google의 에이전트 오케스트레이션 런타임입니다. 에이전트는 상태를 계속 누적하고, 강한 격리가 필요하고, 모델 API와 툴 서버를 호출하며, 루프에 빠지면 돈을 태울 수 있다는 점에서 일반 마이크로서비스나 배치 작업과 다르다는 문제의식에서 출발해, Task(격리된 샌드박스 실행)·Workspace(Git 저장소·MCP 서버·스킬 패키지 사전 구성)·Gateway(호스트 화이트리스트 기반 네트워크 제한)·Model(LLM 설정과 자격 증명 관리) 네 가지 선언적 추상화로 문제를 쪼갭니다. Kubernetes 위에서 선언적 YAML 매니페스트로 컨트롤 플레인을 굴리는 구조는, Agent Substrate 기반 샌드박스 실행에 상태 체크포인팅과 정지/재개, 실행 중인 샌드박스로의 셸 접속 같은 디버깅 기능까지 얹은 것으로, 에이전트 워크로드 전용 오케스트레이터를 밑바닥부터 설계할 때 어떤 추상화 단위가 필요한지 보여주는 좋은 참고 자료입니다.
