### guenchi/Goeteia

- <https://github.com/guenchi/Goeteia>
- 언어: Scheme, 스타: 63, 생성일: 2026-06 이후

Scheme을 WebAssembly(Wasm GC 확장 포함)로 컴파일하는 self-hosting 컴파일러 겸 그래픽 웹 툴킷입니다. 값이 Wasm 엔진의 GC 힙에 직접 살도록 설계해(고정소수는 unboxed `i31ref`, pair는 GC struct) 호스트 쪽 별도 객체 표현이 필요 없고, 매크로 확장 → 인라이닝 → 대입 변환 → dead code elimination → 코드 생성으로 이어지는 컴파일 파이프라인을 WebGL/WebGPU 그래픽 스택과 함께 제공합니다. 컴파일러가 자기 자신을 컴파일했을 때 바이트 단위로 동일한 결과를 내는지 검증하는 self-hosting fixpoint 테스트를 갖추고 있고, Wasm GC를 대상으로 하는 것과 순수 JavaScript를 대상으로 하는 것 두 백엔드가 모든 최적화 패스를 공유합니다. Scheme 컴파일러 백엔드를 최신 Wasm GC 타겟으로 직접 구현한 사례라 선정했습니다.
