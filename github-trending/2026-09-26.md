오늘 트렌딩은 "에이전트에게 조직과 기억을 맡긴다"는 흐름이 상위권을 그대로 채운 하루입니다. 어제부터 이어진 에이전트 오케스트레이션 플랫폼(paperclip)과 에이전트 기억 시스템(hindsight)이 나란히 최상위를 지켰고, 여기에 에이전트가 다루는 오피스 문서 런타임(univer)까지 더해지면서 "에이전트가 일하는 조직의 뼈대"를 만드는 프로젝트들이 한 축을 이룹니다. 다른 한 축에는 모델을 가볍게 만드는 최적화 라이브러리(NVIDIA Model-Optimizer)와 여전히 20만 스타를 넘기며 꾸준히 커밋이 쌓이는 TensorFlow가 자리하는데, 에이전트 상위 계층이 화려해질수록 그 밑을 받치는 추론 최적화·프레임워크 계층의 존재감도 함께 부각되는 모습입니다.

## paperclipai/paperclip

- <https://github.com/paperclipai/paperclip>
- 언어: TypeScript
- 오늘 스타: 2,589 (총 86,309)

여러 AI 에이전트를 "회사의 직원"처럼 조직도·업무·거버넌스 구조 안에서 관리하는 오픈소스 플랫폼입니다. Node.js·PostgreSQL 백엔드에 pnpm 모노레포로 구성되어 있고, DB 트랜잭션 기반의 원자적 작업 체크아웃으로 중복 작업과 비용 폭주를 막는다는 점, 에이전트별 토큰 예산과 승인 게이트로 거버넌스를 강제한다는 점이 눈에 띕니다. 개별 에이전트를 잘 만드는 단계를 넘어 "여러 에이전트를 어떻게 조직으로 운영할 것인가"를 시스템 설계 문제로 다루는 사례라, 멀티 에이전트 아키텍처를 공부할 때 참고하기 좋습니다.

## vectorize-io/hindsight

- <https://github.com/vectorize-io/hindsight>
- 언어: Python
- 오늘 스타: 2,152 (총 31,027)

단순히 대화 기록을 저장하는 게 아니라 에이전트가 경험에서 배우도록 설계된 기억 시스템입니다. 사실·경험·관찰·정신모델 등 여러 종류의 메모리를 구조화하고, 저장(retain)·검색(recall)·성찰(reflect) 세 가지 연산으로 나눠 처리하는데, 검색 단계에서 시맨틱·키워드·그래프·시간 기반 전략을 병렬로 돌린다는 점이 구조적으로 흥미롭습니다. PostgreSQL+pgvector 위에서 동작하고 LiteLLM·MCP 등 60개 이상의 프레임워크와 연동된다는 점까지 보면, "에이전트 기억"을 하나의 검색·저장 인프라 문제로 어떻게 풀어내는지 확인할 수 있는 프로젝트입니다.

## NVIDIA/Model-Optimizer

- <https://github.com/NVIDIA/Model-Optimizer>
- 언어: Python
- 오늘 스타: 354 (총 4,638)

양자화·지식 증류·프루닝·신경망 구조 탐색·추측 디코딩(speculative decoding) 등 최신 모델 경량화 기법을 하나로 묶은 라이브러리로, TensorRT-LLM·TensorRT·vLLM 같은 배포 프레임워크로 넘기기 전 모델을 압축하는 역할을 합니다. 다양한 최적화 기법을 단일 API 아래 통합해두었다는 점에서, 서로 다른 압축 기법들이 실제로 어떻게 조합되고 어느 지점에서 트레이드오프가 발생하는지 비교하며 공부하기 좋은 레포입니다. 에이전트 오케스트레이션 레포들이 상위권을 채운 오늘, "그 에이전트가 결국 호출하는 모델을 얼마나 가볍게 만들 것인가"라는 하부 계층의 질문을 대표하는 프로젝트입니다.

### skillsynchq/txcript

- <https://github.com/skillsynchq/txcript>
- 언어: Rust
- 스타: 137, 생성일: 2026-06-25

Claude Code, Codex, OpenCode 등 서로 다른 코딩 에이전트 툴의 세션 기록(대화, 추론 과정, 도구 호출 이력)을 서로 다른 포맷 사이에서 변환해주는 "에이전트 대화용 판독" 도구입니다. 각 에이전트 고유의 세션 저장 형식을 `Transcript<Common>`이라는 공통 중간 표현으로 매핑한 뒤, 이 표현을 거쳐서만 포맷 간 변환이 이루어지도록 설계한 추상화 계층이 핵심입니다. Rust로 작성된 코어 라이브러리를 WebAssembly로 컴파일해 브라우저·Node.js에서도 그대로 쓸 수 있게 했고, CLI와 MCP 연동, 포맷별 스펙 문서까지 갖추고 있어 서로 다른 시스템 간 데이터를 무손실로 옮기는 중간 표현 설계 방식을 살펴보기 좋은 프로젝트입니다.
