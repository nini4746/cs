## obra/superpowers

- <https://github.com/obra/superpowers>
- 언어: Shell
- 오늘 스타: 785 (총 323,900)

코딩 에이전트가 설계→계획→TDD 실행→리뷰 순서를 지키도록 강제하는 방법론 스킬 프레임워크입니다. 세션 시작 시 주입되는 `using-superpowers` 스킬이 작업 전에 관련 스킬 점검을 "제안이 아니라 의무"로 만들고, 브레인스토밍으로 의도를 좁힌 뒤 git worktree로 작업을 격리하고, 파일 경로·코드·검증 단계가 담긴 세부 계획을 세워 실패하는 테스트부터 작성하는 TDD로 실행하는 체인을 구성합니다. Testing·Debugging·Collaboration·Meta 같은 카테고리로 스킬을 나누고, 세션 전체를 다시 읽어 스킬이 제대로 트리거됐는지 진단하는 `diagnosing-superpowers`까지 갖춘 점에서, 프롬프트만으로 에이전트 행동을 얼마나 강하게 규율할 수 있는지 보여주는 사례로 참고할 만합니다.

## HKUDS/CLI-Anything

- <https://github.com/HKUDS/CLI-Anything>
- 언어: Python
- 오늘 스타: 687 (총 62,522)

"오늘의 소프트웨어는 사람을 위해 만들어졌지만 내일의 사용자는 에이전트일 것"이라는 전제로, 전문 소프트웨어의 소스 코드에 7단계 파이프라인(분석 → GUI-API 매핑 → 명령·상태 설계 → Click 기반 CLI 구현 → 테스트 → 문서화 → PATH 배포)을 돌려 CLI를 생성하는 코딩 에이전트용 플러그인입니다. 생성된 CLI는 GUI를 재구현하지 않고 헤드리스 LibreOffice나 Blender Python API, `melt` 같은 실제 백엔드를 그대로 호출하며, 모든 명령이 `--json` 출력과 `SKILL.md`를 갖춰 에이전트가 발견·호출하기 쉽게 되어 있습니다. `pip install cli-anything-hub`로 설치하는 레지스트리 CLI-Hub가 30여 개 하네스에 걸쳐 2,400개 이상의 테스트를 보유한다고 밝히는데, GUI 자동화나 부분 재구현 대신 "실제 소프트웨어의 전체 기능에 결정적이고 스크립트 가능하게 접근하는" 방식을 구체적인 아키텍처로 보여줍니다.
