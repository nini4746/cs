- 오늘 스타: 657 (총 11,400)

키 25cm, 무게 800g짜리 2족 보행 오리 로봇 Microduck의 "뇌" 소프트웨어입니다. Rust로 작성된 단일 워크스페이스에 프레임워크 없이 데몬들을 나눠 두었는데, 제어 루프를 맡는 `robotd`가 15개 서보를 50Hz로 구동하고, 업데이트·롤백을 맡는 `updaterd`, 블루투스·게임패드·카메라·깊이 센서를 각각 맡는 데몬들이 유닉스 소켓 위의 JSON-RPC 하나로 통신합니다. 제어 정책은 별도 레포(microduck_rl)에서 MuJoCo와 PPO로 학습해 ONNX로 내보내는 구조인데, 강화학습으로 만든 정책과 실시간 제어 데몬을 어떻게 나눠서 운영하는지, 그리고 업데이트 실패 시 롤백까지 챙기는 소규모 로보틱스 시스템을 어떻게 설계하는지 참고할 만합니다.

### pilot-protocol/pilotprotocol

- <https://github.com/pilot-protocol/pilotprotocol>
- 스타: 146
- 생성일: 2026-02-07

AI 에이전트에게 고정 주소와 암호화된 P2P 채널, 신뢰 모델을 주는 오버레이 네트워크로, Go 표준 라이브러리만으로 작성됐다고 밝힙니다. STUN으로 NAT 환경을 파악하고 UDP 홀펀칭으로 직접 연결을 뚫되 실패하면 릴레이로 우회하며, 그 위에 슬라이딩 윈도우·SACK·AIMD 혼잡 제어·네이글 병합까지 갖춘 TCP 유사 신뢰 전송 계층을 직접 구현했습니다. 키 교환은 Ed25519로 서명한 X25519, 터널 암호화는 AES-256-GCM을 쓰고, 노드는 기본적으로 비공개이며 상호 핸드셰이크로 신뢰를 맺는 구조입니다. `go test`로 1048개 테스트를 통과한다고 밝히고 있고 와이어 스펙·백서·IETF 인터넷 드래프트 두 건까지 공개해 둔 것을 보면, NAT 트래버설과 혼잡 제어를 표준 라이브러리만으로 바닥부터 재구현하면서도 문서화 수준을 상당히 높게 유지하고 있습니다.
