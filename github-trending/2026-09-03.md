오늘 트렌딩은 "AI 코딩 에이전트에게 무엇을 스킬로 넘길 것인가"라는 흐름이 상위권 대부분을 채운 하루입니다. 불필요한 코드를 안 쓰게 만드는 라지니스 규칙(ponytail), 엔지니어링 습관을 스킬 파일로 압축한 모음(mattpocock/skills), 대화 채널을 넘나들며 스스로 학습하는 에이전트(hermes-agent), 68개 서브에이전트와 286개 스킬을 번들한 하네스(ECC)까지, 에이전트를 얼마나 규율 있게 굴릴지에 대한 실험이 여러 각도에서 동시에 벌어지고 있습니다. 그 사이에서 20년 넘게 C++ 진영의 표준 포맷팅 라이브러리로 자리잡은 fmt가 나란히 오른 것도 눈에 띕니다.

## DietrichGebert/ponytail

- <https://github.com/DietrichGebert/ponytail>
- 언어: JavaScript
- 오늘 스타: 2,138 (총 122,960)

AI 에이전트가 코드를 쓰기 전에 "이미 필요한가, 코드베이스에 있는가, 표준 라이브러리에 있는가, 플랫폼 기능으로 되는가, 설치된 의존성으로 되는가, 한 줄로 되는가"를 순서대로 점검하게 만드는 "라지니스 사다리(laziness ladder)" 규칙 세트입니다. Claude Code, Codex, Cursor 등 20개 이상의 에이전트에 훅과 스킬 커맨드(`/ponytail-review` 등)로 주입되는 구조이며, 실제 FastAPI+React 저장소에서 12개 기능 작업을 벤치마크해 "코드량 평균 54% 감소, API 비용 20% 절감, 실행 27% 단축"을 측정했다고 밝히고 있습니다. 안전장치를 그대로 유지하면서 과잉 생성만 줄이겠다는 목표가, 에이전트에게 자율성을 주되 규율을 코드로 강제한다는 점에서 오늘 트렌딩 전체의 주제를 가장 압축적으로 보여줍니다.

## mattpocock/skills

- <https://github.com/mattpocock/skills>
- 언어: TypeScript
- 오늘 스타: 1,576 (총 246,558)

TypeScript 교육자 Matt Pocock이 자신의 `.agents` 디렉터리에서 그대로 가져왔다는 에이전트 스킬 모음입니다. 요구사항을 잘못 이해하는 문제는 `/grill-me`로, 장황한 응답은 공유 도메인 언어(`CONTEXT.md`)로, 버그는 `/tdd`·`/diagnosing-bugs`의 피드백 루프로, 무너지는 아키텍처는 `/improve-codebase-architecture`로 대응하는 식으로 실패 유형별 스킬을 나눠둔 점이 특징입니다. `npx skills@latest add`로 설치하는 배포 구조와 함께, "에이전트가 개발 속도를 높이는 만큼 소프트웨어 엔트로피도 가속한다"는 저자의 문제의식이 이 저장소 전체를 관통합니다.

## fmtlib/fmt

- <https://github.com/fmtlib/fmt>
- 언어: C++
- 오늘 스타: 955 (총 24,823)

C stdio와 C++ iostream을 대체하는 빠르고 안전한 포맷팅 라이브러리로, C++20 `std::format`과 C++23 `std::print`의 참조 구현이자 사실상의 표준으로 자리잡은 프로젝트입니다. 위치 인자 기반 포맷 API와 지역화 지원이 핵심이며, 이미 다수의 컴파일러 표준 라이브러리 구현에 영향을 준 성숙한 코드베이스입니다. 에이전트 스킬 프로젝트들이 쏟아지는 오늘 트렌딩에서, 수년간 검증을 거쳐 언어 표준에 편입된 기초 라이브러리가 여전히 활발히 개발되고 있다는 사실 자체가 대비되어 눈에 띕니다. API 설계와 성능을 동시에 잡은 포맷팅 라이브러리 구현을 공부하기에 좋은 레퍼런스입니다.

- 언어: Python
- 오늘 스타: 778 (총 240,611)

Telegram, Discord, Slack, WhatsApp, Signal, CLI 등 여러 채널로 접속할 수 있는 "스스로 성장하는" 에이전트입니다. 경험에서 스킬을 만들고 사용 중에 개선하며, FTS5 검색과 LLM 요약으로 과거 대화를 회상하는 영속 메모리를 갖추고 있습니다. 로컬·Docker·SSH·Modal·Daytona·Vercel Sandbox 등 7가지 실행 백엔드와 MCP 연동, 다중 LLM 프로바이더 지원으로 벤더 종속 없이 5달러짜리 VPS에서도 돌아간다는 점을 내세웁니다. 대화형 에이전트에 지속적 메모리와 자율적 스킬 생성을 어떻게 엮는지 살펴보기 좋은 사례입니다.

"계획 → 테스트 → 구현 → 리뷰 → 검증 → 기억 → 개선"이라는 워크플로를 강제하는 에이전트 하네스로, 68개의 전문화된 서브에이전트와 286개의 재사용 가능한 스킬, 94개의 커맨드를 번들로 제공합니다. ## 오늘의 히든잼

### aalpar/wile

- <https://github.com/aalpar/wile>
- 언어: Go, 스타: 61
- Go 애플리케이션에 임베딩하도록 설계된 순수 Go 구현 R7RS-small Scheme 인터프리터입니다. Flatt의 "sets-of-scopes" 모델을 따르는 위생적 매크로(hygienic macros), 제대로 된 꼬리 호출(proper tail calls), 일급 continuation, 정수·유리수·부동소수점·임의 정밀도·복소수를 아우르는 완전한 수치 타워(numeric tower)까지 구현하고 있어 Scheme 처리기의 핵심 난제들을 대부분 정면으로 다룹니다. `test` 디렉터리와 CI 워크플로, 매크로 시스템·continuation·수치 타워를 각각 설명하는 문서를 갖추고 있고, 임베딩 API에서 노출 표면을 프로파일 단위로 제한하는 샌드박싱 기능까지 있어 단순 장난감 인터프리터를 넘어서는 완성도를 보여줍니다. 언어 구현 이론(위생적 매크로, continuation)을 실제 코드로 확인하고 싶을 때 참고하기 좋습니다.

### maximecb/plush

- <https://github.com/maximecb/plush>
- 언어: Rust, 스타: 127
- 교육과 창작 코딩을 위한 미니멀 프로그래밍 언어이자 레지스터 기반 인터프리터로, JavaScript·Lox·Lua·Python·Rust에서 영향을 받았다고 밝히고 있습니다. 전역 VM 락 없이 동작하는 액터 기반 병렬성을 지원하며, `cargo test`로 실행되는 테스트 스위트와 플라즈마 이펙트 같은 그래픽 데모 예제, 최소 의존성을 유지해 설치와 포팅을 쉽게 한다는 명확한 설계 철학을 갖추고 있습니다. Ruby의 YJIT를 만든 Maxime Chevalier-Boisvert가 "재미있는 사이드 프로젝트"라고 소개하는 만큼 언어 구현 실력이 뒷받침된 코드베이스이며, 레지스터 기반 VM을 처음부터 설계하는 과정을 가볍게 따라가 보기 좋은 프로젝트입니다.

### rayzor-blade/ash

- <https://github.com/rayzor-blade/ash>
- 언어: Rust, 스타: 7
- Haxe가 컴파일하는 HashLink 바이트코드(`.hl`)를 실행하는 Rust 기반 가상머신으로, NaN-boxing 인터프리터(Tier 0) → Cranelift JIT(Tier 1) → LLVM 21 MCJIT(Tier 2)로 이어지는 계층형 실행 구조를 갖추고 있습니다. 타입이 있는 phi-SSA 중간표현(AIR)을 도입해 null 체크 제거, GVN/CSE, LICM, 인라이닝 등 표준적인 컴파일러 최적화 파이프라인을 적용하고, 메모리 관리는 보수적 스택 스캐닝 방식의 Immix GC로, 동시성은 협조적 스택풀 파이버로 처리합니다. Haxe 4.3.6 공식 테스트 스위트의 "1069개 중 1069개"를 통과했다고 명시하고 GitHub Actions로 린트·적합성·벤치마크를 자동화해 두는 등, 스타 수 대비 검증 수준이 매우 높습니다. 인터프리터에서 시작해 다단계 JIT과 GC까지 갖춘 완결된 VM 구현을 통째로 읽어보고 싶을 때 특히 값진 자료입니다.
