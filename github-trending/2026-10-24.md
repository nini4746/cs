오늘 트렌딩은 "에이전트를 어떻게 안전하게 돌릴 것인가"라는 질문이 상단을 거의 독점하는 하루입니다. 지난주에도 1위였던 보안 감사 스킬(security-audit-skill)이 오늘도 2천 개 넘는 스타를 더 쌓으며 자리를 지켰고, 그 옆에는 NVIDIA가 내놓은 자율 에이전트용 샌드박스 런타임(OpenShell)과 AWS가 공식 지원하는 에이전트 MCP 서버 모음(agent-toolkit-for-aws)이 나란히 올라와 있습니다. 여기에 "AI 티 나는" 디자인을 피하게 해주는 스킬(hallmark)과 Claude Code 입문 가이드(claude-howto)까지 겹치면서, 에이전트를 실행·검증·디자인·학습시키는 생태계 전반이 동시에 달아오르고 있는 모습입니다. 보안·격리·클라우드 통합이라는 세 축이 한 번에 상위권에 오른 것은, 에이전트 활용이 코드 작성을 넘어 운영 인프라 영역으로 넘어가고 있다는 신호로 읽힙니다.

- 오늘 스타: 2,271 (총 43,355)

- 오늘 스타: 893 (총 19,206)

### keegan0521/CinderVM

- <https://github.com/keegan0521/CinderVM>
- 언어: Rust
- 스타: 66
- 생성일: 2026-10-21

장시간 실행되는 에이전트 작업을 위한 결정론적 바이트코드 VM입니다. 호스트 코루틴 대신 고정 4바이트 명령어 집합(`cdx/4`) 위에서 에이전트 실행을 모델링해, 중단된 상태를 저장·전송·재생할 수 있는 바이트열로 만드는 것이 핵심 설계입니다. 인터프리터는 I/O를 직접 하지 않고 효과가 필요하면 트랩을 던져 호스트가 답을 주입하게 하며, 부동소수점은 비결정적이라 제외하고 정수 연산은 래핑 i64만 허용합니다. JVM 스타일의 추상 해석 검증기가 스택 깊이·분기 대상·미터링 명령어 존재를 미리 검사해야만 이미지가 만들어질 수 있게 막아둔 점, 그리고 각 레코드가 이전 레코드의 해시를 커밋해 변조를 감지하는 해시 체인 재생 저널 설계가 돋보입니다. 아직 0.x 버전이지만 검증기와 인터프리터를 상호 퍼징하는 전용 퍼저까지 갖추고 있어, "에이전트 실행을 어떻게 재현 가능하게 만들 것인가"라는 문제를 VM 설계로 정면 돌파한 사례로 볼 만합니다.
