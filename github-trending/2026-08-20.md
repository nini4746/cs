## mattpocock/skills

- <https://github.com/mattpocock/skills>
- 언어: Shell
- 오늘 스타: 2,267 (총 225,368)

TypeScript 교육자로 유명한 Matt Pocock이 자신의 `.agents` 디렉터리에서 실제로 쓰는 코딩 에이전트용 스킬들을 그대로 공개한 저장소로, 오늘 트렌딩에서 가장 큰 폭으로 스타가 늘었습니다. 각 스킬은 에이전트가 특정 작업(리팩터링, 테스트 작성, 라이브러리 사용 규약 등)을 수행할 때 따라야 할 절차와 규칙을 담은 파일 형태로 제공되어, "실무자의 노하우를 에이전트가 읽을 수 있는 지시문으로 코드화"하는 방식을 구체적으로 관찰할 수 있습니다. 스킬을 별도 프레임워크 없이 디렉터리와 마크다운만으로 조직하는 최소한의 구조를 참고하기 좋습니다.

## obra/superpowers

- <https://github.com/obra/superpowers>
- 언어: Shell
- 오늘 스타: 749 (총 274,746)

## AprilNEA/OpenLogi

- <https://github.com/AprilNEA/OpenLogi>
- 언어: Rust
- 오늘 스타: 1,225 (총 11,334)

Logitech Options+를 대체하는 로컬 우선(local-first) 마우스 설정 도구를 Rust로 구현한 프로젝트로, 계정 로그인이나 텔레메트리 없이 HID++ 프로토콜을 직접 다뤄 버튼 리매핑·DPI·SmartShift를 제어합니다. GUI에는 GPUI를 쓰고, 무거운 공식 소프트웨어 대신 하드웨어 통신 계층(HID++)을 밑바닥부터 재구현했다는 점에서, 상용 주변기기 드라이버를 오픈소스로 다시 짤 때 어떤 프로토콜 계층을 파고들어야 하는지 살펴보기 좋은 사례입니다. 프라이버시와 로컬 우선 설계를 시스템 프로그래밍 관점에서 함께 볼 수 있습니다.

## modular/modular

- <https://github.com/modular/modular>
- 언어: Mojo
- 오늘 스타: 340 (총 27,627)

AI 워크로드를 위한 Mojo 언어와 MAX 추론 엔진을 함께 담은 Modular 플랫폼의 공식 저장소입니다. Mojo는 Python 문법과의 친화성을 유지하면서 시스템 프로그래밍 수준의 성능과 하드웨어 제어를 노리는 언어이고, MAX는 그 위에서 모델 서빙·추론을 최적화하는 런타임입니다. 파이썬 생태계의 편의성과 저수준 성능 사이의 간극을 하나의 언어·플랫폼으로 메우려는 접근을 관찰하기 좋으며, AI 인프라를 언어 설계 차원에서 다시 생각하는 시도를 공부할 수 있습니다.

### Geekgineer/needle-rs

- <https://github.com/Geekgineer/needle-rs>
- 언어: Rust, 스타: 65, 생성일: 2026-05-17

브라우저·엣지 워커·CLI·Python에서 서버나 API 키 없이 도는 tool-calling 추론 런타임을 순수 Rust로 구현해 WebAssembly로 컴파일한 프로젝트입니다. 26M~45M 파라미터의 소형 Needle 트랜스포머 두 세대를 나란히 지원하며, 런타임 크기가 414KB(gzip 163KB)에 지나지 않고 외부 의존성이 없습니다. Walsh-Hadamard 변환 기반 역양자화, ring-buffer KV 캐시, online softmax, 제약 기반 JSON 디코딩 같은 최적화를 직접 구현했고, 상위 구현과의 수치 일치(최대 상대 오차 1.9e-5, v1은 560/560 토큰 일치)를 검증한 데다 253개 Rust 테스트와 36개 WASM assertion을 CI에서 돌리고 벤치마크·아키텍처 문서까지 함께 커밋해둔 점에서 품질이 높다고 판단해 선정했습니다.

### capsulerun/vpod

- <https://github.com/capsulerun/vpod>
- 언어: Rust, 스타: 69, 생성일: 2026-05-17

신뢰할 수 없는 프로세스를 격리된 리눅스 환경에서 1초 이내에 띄워 코드를 실행하고 상태를 유지하는 경량 샌드박스로, 격리 방식이 특이합니다. 완전한 RISC-V 시스템(RV64GC, 단일 vCPU)을 WebAssembly로 컴파일해 게스트 커널과 프로세스가 WASM 선형 메모리 안에서만 존재하도록 하고, WASI 0.2 경계로 바깥과의 접점을 통제합니다. 미리 부팅해둔 리눅스 상태를 스냅샷으로 밀리초 단위에 복원하고, 자주 실행되는 RISC-V 경로를 AOT로 네이티브 변환해 성능을 끌어올리는 구조입니다. Rust 코어에 Python·TypeScript SDK를 얹었고, fmt·clippy·Rust 단위 테스트·다중 SDK 통합 테스트를 CI에서 돌리며 아키텍처 문서와 한계까지 정직하게 밝혀둔 점에서 선정했습니다.

- 언어: Zig, 스타: 57, 생성일: 2026-06-14

HTML을 스크린샷이 아니라 텍스트가 텍스트로 남는 진짜 벡터 PDF로 변환하는 라이브러리로, 텍스트 선택·검색·복사가 되고 링크는 PDF 주석으로, 폰트는 서브셋으로 임베드됩니다. 레이아웃과 PDF 생성을 Zig로 밑바닥부터 구현해 WebAssembly로 컴파일하고, 그 위에 타입이 붙은 TypeScript API를 얹은 3계층 구조입니다. 기존 솔루션을 감싸는 대신 렌더러를 직접 작성했고, Zig·렌더러 테스트 스위트와 React 통합 테스트 앱을 갖췄으며, CSS 지원 매트릭스와 프레임워크별 가이드 문서, html2pdf.js 대비 33% 빠른 렌더링·85.8% 작은 파일 크기를 보이는 벤치마크까지 제시한 점에서 선정했습니다.
