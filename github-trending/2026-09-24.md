## vectorize-io/hindsight

- <https://github.com/vectorize-io/hindsight>
- 언어: Python
- 오늘 스타: 1,607 (총 27,188)

단순히 과거 대화를 검색해 돌려주는 RAG 방식을 넘어, 에이전트가 시간이 지나며 스스로 학습하고 개선하도록 만든 메모리 플랫폼입니다. 사실·경험을 저장하는 Retain, 시맨틱·키워드·그래프·시간 기반 검색을 병렬로 수행하는 Recall, 패턴을 종합해 새로운 통찰을 만드는 Reflect 세 연산을 중심으로, 세계 사실과 에이전트 경험을 증거 기반 관찰과 정신 모델·지식 페이지로 계층화해 저장합니다. PostgreSQL+pgvector(또는 Oracle AI Database)를 저장소로 쓰고 25개 이상의 LLM 프로바이더와 Python·Node.js·Go 클라이언트를 지원하며, LongMemEval 벤치마크에서 검증된 성능과 60개 이상 프레임워크 연동을 내세워 실무 채택이 빠르게 늘고 있습니다. RAG와 구분되는 '에이전트 기억'을 어떤 자료구조와 연산으로 설계하는지 참고하기 좋습니다.
