오늘 GitHub 트렌딩은 "AI 에이전트를 어떻게 다룰 것인가"라는 주제가 상위권을 거의 그대로 채운 하루입니다. 에이전트에게 안전한 실행 환경을 주는 샌드박스(OpenShell), 대화를 넘어 기억을 축적하게 하는 메모리 시스템(Hindsight), 조직 안에서 여러 에이전트를 관리하는 오케스트레이션 플랫폼(Paperclip)이 나란히 오르면서, 코드를 짜는 단계를 넘어 에이전트를 "고용"하고 "통제"하는 인프라 쪽으로 관심이 옮겨가는 흐름이 뚜렷합니다. 여기에 로컬에서 완전히 동작하는 오픈소스 음성 합성 도구(VoiceStudio)와 AI 어시스턴트를 내장한 경량 DB 클라이언트(dbx)까지 겹치면서, "로컬·오픈소스·AI 내장"이라는 세 키워드가 오늘 트렌딩을 관통합니다.

## NVIDIA/OpenShell

- <https://github.com/NVIDIA/OpenShell>
- 언어: Rust
- 오늘 스타: 978 (총 10,160)

자율 AI 에이전트가 파일·API·자격증명에 무제한 접근 없이 안전하게 닿을 수 있게 만든 런타임/샌드박스입니다. 커널 수준 격리로 에이전트별 파일 접근과 시스템 콜을 제한하고, 정책 변경은 형식 검증(formal verification)을 거쳐 위험한 권한 부여를 사전에 잡아내며, 에이전트는 실제 자격증명을 절대 보지 못하고 승인된 요청에만 주입되는 구조가 핵심입니다. Rust로 작성한 커널 로직 위에 Python/TypeScript SDK를 올리고 게이트웨이-슈퍼바이저-샌드박스로 나눈 아키텍처, Kubernetes/Docker 배포까지 갖췄습니다. NVIDIA가 공개한 프로젝트로, "에이전트 함대"를 실제 운영 환경에 풀 때 정책 기반 격리를 어떻게 설계하는지 참고하기 좋습니다.

Retain(저장)·Recall(의미/키워드/그래프/시간 기반 검색)·Reflect(깊은 분석으로 새로운 연결을 형성)라는 세 연산이 핵심 구조이고, LongMemEval 벤치마크에서 RAG나 지식 그래프 방식보다 앞선 성능을 보인다고 소개합니다.
