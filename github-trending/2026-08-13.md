오늘 트렌딩은 "에이전트를 더 잘 쓰게 만드는 도구"가 상위권을 대거 차지한 하루입니다. 에이전트가 만든 다이어그램에서 티를 빼는 스킬(diagram-design), 컨텍스트를 그래프로 관리하는 인프라(semantica), 그리고 Anthropic이 공식 공개한 Agent Skills 저장소(skills)까지, "에이전트를 어떻게 확장하고 신뢰할 것인가"라는 질문이 여러 각도에서 반복됩니다. 여기에 엣지 디바이스용 초경량 파운데이션 모델(needle)과 온디바이스 받아쓰기 앱(FluidVoice)이 더해지면서, 클라우드가 아니라 로컬·기기 위에서 AI를 돌리려는 흐름도 함께 눈에 띕니다.

## cathrynlavery/diagram-design

- 언어: HTML
- 오늘 스타: 4,504 (총 13,285)

## semantica-agi/semantica

- <https://github.com/semantica-agi/semantica>
- 언어: Python
- 오늘 스타: 727 (총 6,238)

"Context와 Accountable AI Systems를 위한 그래프 네이티브 인프라"를 표방하는 프로젝트로, 지식 그래프·온톨로지·프로비넌스(provenance) 같은 토픽을 두루 다룹니다. LLM 에이전트가 참조하는 컨텍스트를 단순 벡터 검색이 아니라 그래프 구조로 관리하면서 결정의 근거를 추적 가능하게 만드는 접근인데, RAG의 한계로 자주 지적되는 "왜 이 답이 나왔는지 설명할 수 없다"는 문제를 그래프 기반 프로비넌스로 풀려는 시도로 읽힙니다. 지식 그래프와 설명 가능성(explainable AI)을 함께 공부하기 좋은 사례입니다.

### asaptf/swift-os

- <https://github.com/asaptf/swift-os>
- 언어: Swift
- 스타: 129 (2026-06-04 생성)

Embedded Swift로 처음부터 새로 짠 64비트 ARM 운영체제입니다. 커널이 EL1, 유저랜드가 EL0에서 도는 표준적인 권한 분리에 더해, MMU 기반 프로세스별 주소 공간 분리, SMP 환경에서의 TLB 크로스 CPU shootdown, futex 기반 스레드 동기화까지 구현되어 있고, uid==0 대신 capability(권한 토큰) 기반 보안 모델을 쓰는 점이 눈에 띕니다. 순수 Swift로 짠 sans-IO 네트워킹 코어(이더넷·ARP·IPv4·TCP·DNS)를 갖추고 있고, 이 커널 위에서 실제로 nginx와 Node.js(V8 jitless 모드)가 돈다는 것을 자체 CI로 검증하고 있어, 장난감 OS 수준을 넘어선 구현 깊이를 보여줍니다.

Linux용 고성능 패킷 생성기로, 커널 네트워킹 스택을 우회하는 AF_XDP를 전송 계층으로 써서 iperf 같은 기본 도구와 전용 하드웨어 어플라이언스 사이의 빈틈을 메우는 프로젝트입니다. cgo나 DPDK, libpcap 없이 Go 표준 라이브러리만으로 정적 바이너리 하나에 담아냈다는 점이 인상적이고, 100G Mellanox NIC에서 최소 프레임 기준 초당 1억 3,800만 패킷을 단일 프로세스로 뽑아낸다고 밝히고 있습니다. AF_XDP·eBPF로 커널을 우회하는 고성능 네트워킹 코드를 실전 예제로 뜯어보기 좋습니다.

### 4RH1T3CT0R7/ttf-doom

- <https://github.com/4RH1T3CT0R7/ttf-doom>
- 언어: Python
- 스타: 65 (2026-03-31 생성)

TrueType 폰트에 내장된 30년 된 힌팅 바이트코드 인터프리터 안에서 돌아가는 DOOM 스타일 3D 레이캐스터입니다. C와 비슷한 DSL을 TrueType 바이트코드로 컴파일하는 자체 컴파일러(렉서→파서→코드젠)를 만들고, DDA 레이캐스팅으로 16x16 타일맵을 그린 뒤 glyph의 윤곽선을 재배치해 3D 원근감을 표현하는 방식입니다. 정수만 쓰는 고정소수점 연산(1*4가 0이 되는 것 같은 제약), 반복문이 없어 재귀로 루프를 구현해야 하는 문제 등 폰트 VM의 기이한 제약을 뚫고 451개의 테스트로 검증까지 마쳤다는 점에서, 장난스러운 소재 안에 컴파일러·VM 구현 지식이 진지하게 압축되어 있는 사례입니다.

### nightmarewalker/D-MemFS

- <https://github.com/nightmarewalker/D-MemFS>
- 언어: Python
- 스타: 32 (2026-02-28 생성)

`io.BytesIO`로는 부족하지만 OS 레벨 RAM 디스크를 쓰기는 부담스러운 상황을 위한, 프로세스 내부 전용 가상 파일시스템 라이브러리입니다. 메모리 초과를 사전에 막는 하드 쿼터(`MFSQuotaExceededError`)와 물리 메모리 고갈을 감지하는 메모리 가드, 파일 단위 락과 GIL이 없는 free-threaded Python(3.13t) 호환성까지 갖췄고, 순차 접근에서 랜덤 접근으로 자동 승격되는 스토리지 구조도 구현되어 있습니다. Linux·Windows·macOS 세 플랫폼에서 436개 테스트, 코드 커버리지 97%를 확보하고 있어, 작은 라이브러리지만 VFS 설계와 동시성 제어를 진지하게 다룬 티가 납니다.

### sublang-ai/slc

- <https://github.com/sublang-ai/slc>
- 언어: TypeScript
- 스타: 65 (2026-04-11 생성)

자연어로 쓴 워크플로 설명을 결정론적인 멀티 에이전트 프로그램으로 컴파일하는 도구입니다. 자연어를 정규화된 스펙(GEARS)으로 바꾸고, 이를 다시 XState 기반 유한 상태 기계(FSM)로 변환한 뒤, 마지막으로 실행 가능한 TypeScript 모듈로 링크하는 3단계 파이프라인을 갖추고 있습니다. LLM의 판단을 "상태 사이의 흐름을 정하는 일"이 아니라 "한 상태 안에서의 작업"으로 한정해 제어 흐름 자체는 결정론적으로 유지한다는 설계가 핵심이고, 컴파일러 자신의 phase 정의도 컴파일된 산출물이라 SHA256으로 고정해 드리프트를 막는 자기 호스팅(self-hosting) 구조도 갖추고 있습니다. 자연어 입력을 컴파일러 파이프라인(정규화 → FSM → 코드 생성)으로 다루는 발상을 구체적으로 살펴보기 좋은 사례입니다.
