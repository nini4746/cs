## anthropics/claude-plugins-official

- <https://github.com/anthropics/claude-plugins-official>
- 언어: Python
- 오늘 스타: 1,552 (총 40,039)

Anthropic이 직접 운영하는 공식 Claude Code 플러그인 마켓플레이스입니다. `/plugins`는 Anthropic이 관리하는 내부 플러그인, `/external_plugins`는 서드파티가 제출한 플러그인으로 나뉘어 있고, 각 플러그인은 `.claude-plugin/plugin.json` 메타데이터 파일을 필수로 가지며 MCP 서버 설정, 슬래시 커맨드, 서브에이전트, 스킬을 선택적으로 포함할 수 있습니다. 사용자는 `/plugin install {plugin-name}@claude-plugins-official`로 설치하거나 `/plugin > Discover`에서 둘러볼 수 있고, 서드파티 제출은 품질·보안 기준을 통과해야 승인됩니다. 레포 자체보다는 "에이전트 확장 기능을 마켓플레이스 형태로 큐레이션하고 배포하는 구조"를 참고하기 좋은 사례입니다.

## HKUDS/CLI-Anything

- <https://github.com/HKUDS/CLI-Anything>
- 언어: Python
- 오늘 스타: 716 (총 53,285)

"오늘의 소프트웨어는 사람을 위해 서비스하지만, 내일의 사용자는 에이전트일 것"이라는 구호 아래, GUI 자동화나 재작성 없이 기존 소프트웨어를 감싸는 구조화된 CLI를 생성해주는 프로젝트입니다. Claude Code·Cursor·Codex용 플러그인이 소스를 분석하고 커맨드 그룹을 설계한 뒤 Click 기반 CLI를 구현·테스트·문서화·패키징까지 자동으로 수행하는 7단계 파이프라인이 핵심이며, 생성된 각 CLI는 LibreOffice나 Blender 같은 실제 백엔드를 그대로 호출합니다. CLI-Hub라는 레지스트리로 커뮤니티가 만든 CLI를 설치·검색할 수 있고, 각 도구에 `SKILL.md`를 붙여 에이전트가 발견하게 합니다. "에이전트가 소프트웨어를 쓰게 만드는 방법"으로 GUI 자동화 대신 CLI 래핑을 택한 접근이 특징입니다.

## mksglu/context-mode

- <https://github.com/mksglu/context-mode>
- 언어: TypeScript
- 오늘 스타: 449 (총 30,066)

에이전트의 거대한 툴 출력을 컨텍스트 윈도우 밖으로 빼내는 MCP 서버입니다. 명령과 코드를 격리된 샌드박스 서브프로세스에서 실행하고 실제로 출력된 내용만 에이전트에 돌려주는 방식으로, 자체 벤치마크로는 315KB의 원본 출력이 5.4KB로 줄었다고 밝힙니다. 파일 수정·태스크·에러·사용자 결정 같은 세션 이벤트를 로컬 SQLite에 전문 검색 가능하게 기록해두고, 대화가 압축(compact)된 뒤에도 필요한 상태만 다시 꺼내 씁니다. Claude Code, Gemini CLI, Codex 등 여러 플랫폼에서 PreToolUse·SessionStart 같은 훅과 MCP 툴을 결합해 라우팅하며, 훅을 지원하지 않는 플랫폼에서는 상대적으로 덜 안정적인 지시 파일 방식으로 대체한다고 설명합니다.

CI에서 clippy·fmt·shellcheck는 물론, 실제 Nextcloud 서버를 상대로 마운트·읽기·쓰기·3-way 병합을 검증하는 nightly E2E 스위트까지 돌리는 점에서, 온디맨드 FUSE 파일시스템을 제대로 구현하는 법을 공부하기 좋습니다.

### Virtastic/openmw-web
