오늘 트렌딩은 크게 두 흐름이 나란히 보입니다. 계정도 전화번호도 필요 없이 블루투스 메시와 Nostr로 동작하는 탈중앙 메시징 앱(bitchat)과, 프레임워크 런타임 없이 시맨틱 HTML을 뽑아내는 셀프호스팅 CMS(Instatic)처럼 "로컬/오프라인 우선"을 내세우는 도구들이 한편에 있고, 다른 한편에는 어제부터 이어지는 사람-에이전트 협업 인프라(buzz, ego-lite)와 여러 코딩 에이전트를 하나의 GUI로 묶는 t3code가 함께 올라 "에이전트를 일상 워크플로에 어떻게 끼워 넣을 것인가"라는 질문이 계속 이어지고 있습니다. 탈중앙화와 에이전트 통합이라는 서로 다른 관심사가 오늘 트렌딩 안에 동시에 담겨 있는 점이 눈에 띕니다.

## permissionlesstech/bitchat

- <https://github.com/permissionlesstech/bitchat>
- 언어: Swift
- 오늘 스타: 1,198 (총 약 29,500)

블루투스 메시와 Nostr 프로토콜을 함께 쓰는 하이브리드 전송 계층을 가진 탈중앙 메시징 앱입니다. 오프라인 근거리 통신은 블루투스 메시로, 인터넷을 통한 전역 통신은 Nostr로 처리하고, 계정이나 전화번호 없이 종단간 암호화된 채팅을 지원하며 geohash 기반 위치 채널과 1:1 다이렉트 메시지를 함께 제공합니다. 서버 없는 메시징 앱에서 근거리·원거리 두 전송 계층을 어떻게 하나의 프로토콜 위에서 자연스럽게 넘나들게 설계하는지 참고하기 좋습니다.

## block/buzz

- <https://github.com/block/buzz>
- 언어: Rust
- 오늘 스타: 1,705 (총 약 12,800)

Block이 만든 셀프호스팅 워크스페이스로, Nostr relay를 기반으로 사람과 AI 에이전트가 같은 이벤트 로그 위에서 코드리뷰·인시던트 대응·릴리스 워크플로를 함께 처리하도록 설계되었습니다. 사흘 연속 트렌딩에 오르며 오늘 다시 1,700개 넘는 스타가 붙었는데, 중앙 relay(WebSocket/REST)에 Postgres(이벤트 저장·검색)·Redis(pub/sub)·S3/MinIO(미디어)를 붙인 Rust 마이크로서비스 구조와, 워크플로 승인 게이트·YAML 기반 자동화 트리거 등을 계속 확장하고 있는 로드맵을 보면 "에이전트를 신원을 가진 참여자로 다루는 협업 인프라"라는 방향이 점점 구체화되고 있습니다.

사람과 AI 에이전트가 같은 브라우저에서 방해 없이 동시에 작업하도록 만든 macOS 브라우저로, 사흘째 트렌딩에 남아 꾸준히 스타가 쌓이고 있습니다. 에이전트마다 격리된 "Space"를 주고 브라우저 기능을 JavaScript 함수로 직접 노출해 여러 단계 작업을 한 번의 호출로 묶어 처리하게 하며, Claude Code나 Codex 같은 기존 에이전트 CLI와 별도 브라우저 인스턴스 없이 연동됩니다. 에이전트 전용 실행 환경을 브라우저 커널 레벨에서 격리하는 설계를 다시 살펴볼 만합니다.

### TaqsBlaze/FlamingoDB

- <https://github.com/TaqsBlaze/FlamingoDB>
- 언어: Go, 스타: 6, 생성일: 2026-07-13

과학 컴퓨팅 워크로드(생물정보학·기후과학·천문학·물리학·머신러닝)를 위해 다차원 데이터 타입을 1급 시민으로 다루는 데이터베이스 엔진입니다. `SQL Query → Lexer → Parser → Planner → Executor → Table Manager → Catalog/Page → Pager/Disk`로 이어지는 클린 아키텍처 파이프라인을 갖췄고, B+ 트리 인덱스와 WAL(write-ahead logging) 기반 크래시 복구, `VECTOR`/`MATRIX`/`TENSOR`/`COMPLEX` 같은 과학 전용 타입, 8KB 고정 페이지 디스크 I/O까지 직접 구현했습니다. "모든 패키지는 단위 테스트가 필수, 모든 버그 수정은 회귀 테스트가 필수"라는 원칙 아래 14개 테스트 스위트가 전부 통과하는 상태를 유지하고 있어, 생성 2주 만에 스타가 적더라도 SQL 엔진을 밑바닥부터 만드는 교과서적인 구조를 갖춘 프로젝트입니다.

### dweve-ai/hedl

- <https://github.com/dweve-ai/hedl>
- 언어: Rust, 스타: 79, 생성일: 2026-01-08

LLM에 데이터를 보낼 때 토큰 소비를 줄이기 위한 구조적 데이터 포맷으로, 스키마를 한 번 선언한 뒤 값만 반복 전송해 JSON보다 토큰을 상당히 줄인다고 주장합니다. `hedl-core`(무의존성 파서)를 중심으로 JSON/YAML/XML/CSV/Parquet/Neo4j Cypher 변환기, CLI, LSP, MCP 서버, C/C++/Python용 FFI, WebAssembly 바인딩까지 19개 크레이트로 나눈 생태계 구조를 갖췄습니다. 유닛·통합·property-based·퍼징 테스트를 포함해 "1만 개 이상의 테스트"와 코어 파서의 "unsafe 코드 0줄"을 명시하고, 7개 실데이터셋·571개 추출 질문으로 여러 LLM을 대상으로 정확도(80.4% vs JSON 70.1%)까지 벤치마크한 점에서 주장을 수치로 검증하려는 태도가 뚜렷합니다. 토큰 효율적인 직렬화 포맷을 설계할 때 파서·스키마·벤치마크를 어떻게 함께 갖추는지 참고할 만합니다.

### nikhilunni/demucs-rs

### danmolitor/forme

- 언어: Rust, 스타: 144, 생성일: 2026-02-17

헤드리스 브라우저나 Chrome 없이 React 컴포넌트와 JSX로 페이지 단위 PDF를 생성하는 레이아웃 엔진입니다. 렌더링 성능을 위해 Rust 엔진을 WebAssembly로 컴파일했고, 콘텐츠를 무한 캔버스가 아니라 실제 페이지 단위로 흘려보내는 "페이지 네이티브 레이아웃"을 채택했으며, TeX와 같은 Knuth-Plass 알고리즘으로 줄바꿈을 최적화하고 rustybuzz로 OpenType 셰이핑(리가처·커닝)과 아랍어·히브리어 같은 RTL 텍스트 자동 방향 감지까지 지원합니다. Node.js·브라우저·엣지 환경에 모두 배포 가능하고 PDF/UA-1(접근성)·PDF/A(보존)·전자서명까지 다루는 문서, 실전 템플릿 9종, 컴포넌트 트리를 검사할 수 있는 VS Code 확장까지 갖춰, 조판 알고리즘을 웹 생태계에 이식할 때 무엇을 신경 써야 하는지 보여주는 프로젝트입니다.
