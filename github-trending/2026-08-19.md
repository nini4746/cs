### NeverSight/NeverC

- <https://github.com/NeverSight/NeverC>
- 언어: C, 스타: 73, 생성일: 2026-05-16

보안 연구와 시스템 프로그래밍을 겨냥한 C23 컴파일러로, LLVM 백엔드에서 C++/ObjC/OpenMP 경로를 걷어내고 x86_64·AArch64만 남긴 가벼운 빌드가 특징입니다. COFF·ELF·Mach-O를 모두 처리하는 통합 링커를 자체 내장해 외부 의존성 없이 Windows PE·Linux ELF·macOS Mach-O·Android ELF로 진짜 크로스 컴파일을 지원하고, 130개의 이름 붙은 컴파일 단계를 순수 C ABI 플러그인 API로 열어둔 구조가 눈에 띕니다. 값 시맨틱 문자열·mimalloc 오버라이드·컴파일 타임 문자열 암호화(xorstr) 같은 LLVM 비트코드 런타임을 언어 차원에서 내장해두었고, 커널 모드 지원과 bad-byte auditing까지 갖춘 DynCode 파이프라인을 통해 위치 독립 실행 코드를 뽑아낼 수 있다는 점에서 선정했습니다.

### fenio/modern-fs-benchmark

- <https://github.com/fenio/modern-fs-benchmark>
- 언어: Python, 스타: 28, 생성일: 2026-07-12

btrfs·ZFS·bcachefs 같은 최신 CoW 파일시스템을 ext4/xfs-on-md/LVM 같은 전통적 구성과 비교하는 지속적 벤치마크 스위트입니다. 단일 디바이스부터 RAID1·RAID6급·RAIDZ, 네이티브/LUKS 암호화, xfs-on-ZFS 같은 계층형 스택까지 26가지 구성 매트릭스를 CI의 loop 디바이스와 실제 하드웨어 양쪽에서 돌리고, 최대 500개 스냅샷 규모의 성능과 10만 개 이상 파일이 있는 대형 디렉터리 확장성까지 측정합니다. "ext4/xfs on md·LVM RAID처럼 기본으로 '안전하다'고 여겨지는 리눅스 구성에는 데이터 체크섬이 없어 손상된 데이터를 조용히 반환할 수 있다"는 점을 지적하며, 의도적으로 데이터를 손상시킨 뒤 자가 복구를 검증하는 corruption 주입 테스트를 성능 측정과 동등한 1급 지표로 다루는 방법론이 신뢰할 만해 선정했습니다.
