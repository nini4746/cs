오늘 트렌딩도 어제와 비슷하게 "에이전트를 어떻게 더 똑똑하고 다루기 쉽게 만들 것인가"라는 주제가 상위권을 채우고 있습니다. 세션 간 기억을 보존하는 메모리 레이어(claude-mem), 여러 에이전트를 채팅방에 모아두는 하네스(OpenMausBot), 에이전트가 만든 UI의 "AI 티"를 잡아내는 디자인 비평 도구(impeccable)는 어제에 이어 오늘도 상위권을 지키고 있고, 각자 컨테이너를 받아 일하는 AI 코워커 플랫폼(OpenBot)까지 더해지면서 에이전트 인프라 쪽의 관심이 하루 더 이어졌습니다. 그 사이에 자미두수(紫微斗数) 명리학 명식을 계산해주는 오픈소스 엔진이 크게 뜬 점은 눈에 띄는 예외인데, 전통적인 규칙 기반 지식 체계를 소프트웨어로 옮기는 작업도 여전히 사람들의 관심을 끈다는 신호로 보입니다.

## thedotmack/claude-mem

- <https://github.com/thedotmack/claude-mem>
- 언어: TypeScript
- 오늘 스타: 1,145 (총 105.7k)

코딩 에이전트에게 세션을 넘나드는 지속적인 기억을 부여하는 프로젝트로, 이미 10만 스타를 넘긴 채 오늘도 1,000개 넘는 스타가 더 붙었습니다. 세션 중 에이전트의 모든 도구 사용 기록을 라이프사이클 훅으로 가로채 AI로 요약하고, 로컬에서 Bun으로 띄운 워커 서비스의 HTTP API를 거쳐 SQLite와 Chroma 벡터 DB를 함께 쓰는 하이브리드(키워드+시맨틱) 검색으로 다음 세션에 관련 컨텍스트를 다시 주입하는 구조입니다. Claude Code뿐 아니라 Codex, Gemini, Copilot 등 여러 하네스를 지원한다고 밝히고 있어, "에이전트 메모리"를 벡터 검색과 로컬 서비스 아키텍처로 구현하는 구체적인 사례로 참고할 만합니다.

### invilso/fly-vpn

- <https://github.com/invilso/fly-vpn> · 언어: Python · 스타 133 · 생성일: 2026-03-16

Fly.io 머신을 일회용 Tailscale exit node로 띄우고 끝나면 통째로 삭제하는 터미널 VPN 앱입니다. Textual로 만든 TUI 아래에서 ACL 점검 → 1회용 인증 키 발급 → 리전별 Fly Machine 기동 → exit node 자동 연결로 이어지는 절차를 거치고, 세션을 끝내면 머신·앱·Tailscale 디바이스를 함께 정리합니다. "UI 전용 앱 레이어 + enum 기반 세션 오케스트레이션 + 클라우드 API 직접 연동"이라는 계층형 설계를 `fly_api.py`·`tailscale_api.py`·`session.py`·`watchdog.py`로 나눠 구현했고, 고아 상태로 남은 Fly 앱을 정리하는 워치독 모드를 cron으로 돌릴 수 있게 해둔 점에서 일시적 인프라를 다루는 자동화 설계를 참고할 만합니다.
