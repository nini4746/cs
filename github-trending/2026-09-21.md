오늘 트렌딩은 "에이전트가 딛고 설 인프라"를 만드는 프로젝트들이 상위권을 채운 하루입니다. UI와 에이전트가 같은 액션 레이어를 공유하도록 설계된 프레임워크(BuilderIO/agent-native)와 화면·마우스·키보드를 직접 조작하는 computer-use 플랫폼(trycua/cua)이 이틀 연속 나란히 자리를 지켰고, 에이전트가 사용할 클라우드 개발 환경과 거버넌스를 제공하는 coder/coder, 서로 다른 코딩 에이전트 사이에서 메모리를 이어주는 akitaonrails/ai-memory까지 겹치면서 "에이전트를 위한 실행 환경·기억·거버넌스"라는 흐름이 뚜렷합니다. 그 사이 유료 시세 서비스의 오픈소스 대안을 표방하는 Open-Dev-Society/OpenStock이 가장 큰 폭으로 스타를 모은 것도 눈에 띕니다.

## Open-Dev-Society/OpenStock

- <https://github.com/Open-Dev-Society/OpenStock>
- 언어: TypeScript
- 오늘 스타: 843 (총 17,389)

유료 시세 서비스에 대한 무료 오픈소스 대안을 표방하는 주식 시장 플랫폼으로, Next.js 15(App Router)·React 19·MongoDB에 Finnhub API와 TradingView 차트를 결합한 구조입니다. Inngest로 예약 작업과 워크플로를 처리하고 Google Gemini API로 개인화된 웰컴 메일·주간 뉴스 다이제스트를 생성하는 등, 단순 시세 조회를 넘어 알림·워치리스트·30개 이상의 해외 거래소 지원까지 갖춘 풀스택 서비스형 오픈소스 프로젝트입니다. AGPL-3.0 라이선스를 택해 수정·배포 시 소스 공개를 강제하는 점도, "무료 도구를 지키기 위한 라이선스 설계"라는 관점에서 참고할 만합니다.

## trycua/cua

- <https://github.com/trycua/cua>
- 언어: HTML
- 오늘 스타: 609 (총 25,544)

어제에 이어 오늘도 상위권을 지킨 computer-use 에이전트 플랫폼입니다. run.cua.ai로 온디맨드 제공되는 격리 클라우드 데스크톱(Cua Fleets), macOS·Windows·Linux를 아우르는 크로스 플랫폼 자동화 드라이버, 폼 작성 같은 특정 작업에 최적화된 소형 모델(CUA-S1), 궤적 데이터를 뽑아내는 평가 프레임워크(Cua Bench)까지 갖추고 있습니다. 포인터·포커스를 방해하지 않는 백그라운드 전달 모드를 두는 등, 단일 데모가 아니라 실제 서비스 규모로 computer-use 에이전트를 운영하는 데 필요한 인프라 계층을 구체적으로 보여줍니다.

## BuilderIO/agent-native

- <https://github.com/BuilderIO/agent-native>
- 언어: TypeScript
- 오늘 스타: 607 (총 5,676)

역시 어제에 이어 트렌딩에 남은 프레임워크로, "에이전트는 UI를 클릭해서 조작하지 않고, UI와 같은 액션 레이어를 통해 동작한다"는 철학이 핵심입니다. 기능을 한 번 "액션"으로 정의하면 에이전트는 이를 도구로, UI는 코드로 호출하는 방식으로 공유하고, 에이전트·UI·HTTP·MCP·A2A·CLI 등 여러 표면에서 동일한 액션과 상태를 동기화합니다. Clips, Design, Slides 같은 예제 애플리케이션을 여럿 곁들여 둔 것을 보면, 사람이 아니라 에이전트를 일급 사용자로 놓고 애플리케이션 구조 자체를 다시 설계하려는 초기 패턴을 구체적인 코드로 살펴볼 수 있습니다.

- <https://github.com/akitaonrails/ai-memory>
- 언어: Rust
- 오늘 스타: 217 (총 7,491)

"Claude Code로 작업하다 중간에 멈추고 같은 디렉터리에서 OpenAI Codex를 켜도, 아키텍처를 다시 설명할 필요가 없다"는 목표를 내세운 크로스 에이전트 메모리 시스템입니다. Rust 단일 바이너리가 마크다운 위키(`wiki/`), 불변 원본 트랜스크립트(`raw/`), FTS5를 갖춘 SQLite 인덱스(`db/`)를 관리하고, 전문 검색·엔티티 매칭·그래프 이웃·선택적 벡터 랭킹을 조합해 검색하는 구조입니다. LLM API 키 없이도 캡처·검색·인계가 동작하는 "제로-LLM 기본값"을 표방하면서 20개 이상의 에이전트와 호환된다고 밝힌 점에서, 특정 벤더에 종속되지 않는 에이전트 메모리 계층을 설계할 때 참고할 만한 구조입니다.

### compnerd/xylem

- <https://github.com/compnerd/xylem>
- 언어: Swift
- 스타: 146 (생성일: 2026-03-06)

UTF-8 XML 1.0 well-formedness를 대상으로 네임스페이스 인식 SAX/DOM 파싱과 XPath 1.0 평가기를 Swift로 처음부터 구현한 라이브러리입니다. 외부 의존성 없이 UTF-8 렉서(XMLCore), 이벤트 기반 스트리밍 파서(SAXParser), 단일 메모리 할당만 쓰는 플랫 아레나 방식 문서 트리(DOMParser), XPath 평가기(XPath)를 모듈로 나눠 필요한 부분만 골라 쓸 수 있게 설계했습니다. DTD 검증이나 외부 엔티티 해석, XSLT는 공격 표면을 줄이기 위해 의도적으로 제외했다고 밝히면서도, W3C XML Test Suite(XMLTS)를 SHA-256 검증까지 곁들여 준수성 테스트로 돌리고 회귀 추적용 벤치마크를 재현 가능하게 공개한 점에서, "무엇을 왜 뺐는지"까지 설명하는 근거 있는 파서 구현으로 판단했습니다.
