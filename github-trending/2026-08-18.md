## volcengine/OpenViking

- <https://github.com/volcengine/OpenViking>
- 언어: Python
- 오늘 스타: 239 (총 29,132)

벡터 스토어 대신 `viking://`라는 가상 파일시스템 프로토콜로 에이전트의 메모리·지식·스킬을 통합 관리하는 컨텍스트 데이터베이스입니다. 콘텐츠를 100토큰짜리 요약(L0), 2천 토큰짜리 구조적 개요(L1), 전체 원문(L2) 세 단계로 나눠 필요한 만큼만 점진적으로 로드하고, 가장 점수가 높은 디렉터리부터 찾아 들어가는 탐색 궤적을 그대로 남겨 디버깅 가능하게 만든 점이 특징입니다. Rust 코어에 Python 바인딩을 얹은 구조이며, 벤치마크에서 메모리 정확도를 24~57%에서 80~83%로 올리고 입력 토큰을 34~91% 줄였다고 밝히고 있어, 검색 결과를 파일시스템처럼 결정론적으로 탐색 가능하게 만드는 설계를 공부하기 좋습니다.
