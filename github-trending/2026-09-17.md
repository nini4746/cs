오늘도 트렌딩 상위권은 에이전트 생태계가 주도합니다. 어제에 이어 알리바바의 코드 리뷰 에이전트(open-code-review)와 Cloudflare의 보안 감사 스킬(security-audit-skill)이 나란히 최상위권을 지키는 가운데, 이번에는 에이전트가 로그인된 브라우저를 직접 조작하게 해주는 도구(BrowserSkill)와 코딩 에이전트를 연구 자동화 워크스페이스로 바꾸는 프로젝트(OpenResearch)가 새로 올라오면서 "에이전트가 다룰 수 있는 도구의 범위"가 브라우저와 연구 실험까지 넓어지는 흐름이 보입니다. 여기에 NSA가 만든 리버스 엔지니어링 프레임워크 Ghidra가 오랜만에 급등한 것도 눈에 띄는데, 에이전트가 만든 코드를 검증하고 취약점을 찾는 흐름과 맞물려 리버싱 도구에 대한 관심이 함께 커진 것으로 보입니다.

## cloudflare/security-audit-skill

- <https://github.com/cloudflare/security-audit-skill>
- 언어: JavaScript
- 오늘 스타: 3,606 (총 9,672)

정찰 → 커버리지 기반 탐색 → 후보 검증 → 구조화된 출력 → 독립 검증 → 중립적 리포트의 6단계로 보안 감사를 자동화하는 코딩 에이전트용 스킬로, 이틀 연속 스타가 급증하며 어제보다 오히려 증가 폭이 커졌습니다. Cloudflare 블로그 "Build your own vulnerability harness"에서 소개했던 사내 다단계·다중 인스턴스 취약점 탐지 시스템의 출발점이 된 단일 저장소 버전이 공개되면서 뒤늦게 화제가 된 것으로 보이는데, 찾아낸 취약점을 처음 보는 별도 에이전트가 검증하게 하는 적대적 검증 구조가 핵심입니다. 벤더가 사내에서 실전 검증한 보안 방법론을 재사용 가능한 스킬 형태로 공개했다는 점에서, 에이전트 기반 감사 파이프라인을 설계할 때 참고할 가치가 큽니다.

## alibaba/open-code-review

- <https://github.com/alibaba/open-code-review>
- 언어: Go
- 오늘 스타: 3,290 (총 33,979)

Git diff를 분석해 라인 단위로 정밀한 리뷰 코멘트를 생성하는 AI 코드 리뷰 CLI로, 사흘째 트렌딩 상위권을 유지하고 있습니다. 파일 선정·번들링·코멘트 위치 지정 같은 결정론적 로직과 맥락 판단이 필요한 LLM 에이전트 역할을 분리한 하이브리드 구조가 핵심이며, 원래 알리바바 내부에서 수만 명이 쓰던 도구를 오픈소스화한 것입니다. 어제 나란히 트렌딩에 오른 security-audit-skill과 함께 놓고 보면, "에이전트가 짠 코드를 다른 에이전트가 리뷰·감사한다"는 이중 검증 구조가 하루짜리 유행이 아니라 자리 잡는 패턴이라는 신호로 읽힙니다.

- <https://github.com/Tencent/BrowserSkill>
- 언어: TypeScript
- 오늘 스타: 1,350 (총 3,800)

Claude Code, Cursor, Codex 등 다양한 코딩 에이전트가 사용자의 이미 로그인된 브라우저를 별도의 "에이전트 전용 창"으로 조작할 수 있게 해주는 도구입니다. `bsk` CLI/데몬, 브라우저 확장, 에이전트 하네스 세 컴포넌트가 로컬 IPC와 웹소켓으로 연결되는 구조로, 로그인 세션을 별도 테스트 계정 없이 재사용하면서도 사람이 직접 쓰는 창과 에이전트가 조작하는 창을 분리해 안전성을 확보한 점이 특징입니다. CAPTCHA나 확인이 필요한 순간에는 사람에게 개입을 요청하는 설계도 갖추고 있어, 에이전트에게 브라우저 권한을 안전하게 위임하는 아키텍처를 공부하기 좋은 사례입니다.

- 오늘 스타: 940 (총 4,941)

Claude Code, Codex 같은 코딩 에이전트를 문헌 조사부터 가설 수립, 실험 실행, 결과물 작성까지 수행하는 연구 에이전트로 바꿔주는 로컬 우선 워크스페이스입니다. Git 워크트리로 여러 연구 방향을 병렬로 격리하고, 실험을 Git 네이티브 트리와 불변 커밋 아카이브로 추적하며, 로컬 머신뿐 아니라 SSH·Slurm·Kubernetes·Ray 등 다양한 환경에 동일한 소스 스냅샷을 실행할 수 있는 구조가 핵심입니다. 코드 실행 이력을 재현 가능한 형태로 버전 관리한다는 발상 자체가, "실험"이라는 비결정적 과정에도 소프트웨어 공학의 재현성 원칙을 적용하려는 시도로 읽힙니다.

## NationalSecurityAgency/ghidra

- <https://github.com/NationalSecurityAgency/ghidra>
- 언어: Java
- 오늘 스타: 912 (총 78,273)

NSA 연구부서가 공개한 소프트웨어 리버스 엔지니어링 프레임워크로, 디스어셈블·디컴파일·그래프 분석·스크립팅을 다양한 프로세서 아키텍처와 실행 파일 포맷에 걸쳐 지원합니다. Java로 작성됐지만 PyGhidra를 통한 파이썬 자동화도 가능하고, Eclipse나 VS Code 확장으로 커스텀 스크립트·익스텐션을 개발할 수 있는 확장형 구조가 특징입니다. 오늘 함께 트렌딩에 오른 코드 리뷰·보안 감사 에이전트들과 나란히 보면, 소스 코드 없이 바이너리 수준에서 취약점을 분석하는 전통적 리버싱 도구가 에이전트 시대에도 여전히 기초 인프라로 쓰이고 있다는 점이 눈에 띕니다.
